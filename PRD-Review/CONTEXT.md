# CONTEXT.md —— PRD-Review 术语与决策记录

> PRD-Review 的术语对齐源与决策日志。

## 一、角色与边界

- 人设：前端 / 后端 / 测试**一审三角色** + **产品专家总审层（兼调度者）**。
- 目标：找 PRD「价值无源、逻辑不通、规则缺仲裁、叫法不统一、文案不准确、无处兜底、无法落地」的点。
- 边界：只审不改；无 Pass/Fail；修改经任务清单交 PRD-Design。
- 归口：术语与文案的**正确性**由产品专家唯一认领（含调度时从 FE / BE 归并的同类问题）；FE-3 / FE-5 只判「反馈有无 / 是否可开发」，BE-5 收窄数据口径、TE-5 收窄可量化性。
- 调度：产品专家对三角色问题做归并去重 / 定级校准 / 冲突裁决 / 归属指派 / 补漏扫描，结果逐条入 `产品评审.md`。

## 二、术语表

| 术语 | 定义 |
|---|---|
| 一审三角色 | 前端/后端/测试各自唯一标准，并行互不可见，独立成文，汇总才合并 |
| 产品专家总审 | 三角色完成后的**总审层 + 调度者**：输入 = PRD 原文 + 三份角色评审；补三角色看不到的问题 + 调度其结论（见下条），不与三角色平级 |
| 核心必查 / 扩展档 | 核心 = PM-1 目标与价值闭环 / PM-2 业务闭环 / PM-3 业务规则完整性 / PM-4 术语 / PM-5 文案 / PM-6 一致性与矛盾，**每次全查**；扩展 = PM-7 异常与业务兜底，命中触发条件（资金交易 / 审核审批 / 第三方对接 / 不可逆操作 / 存量数据）才查，未触发须标「不适用（未触发）」 |
| 调度三角色问题 | 五动作：归并去重 / 定级校准 / 冲突裁决 / 归属指派 / 补漏扫描；命中已有问题标原编号 + 命中角色，不重复编号；结果逐条入 `产品评审.md`（旧称「交叉校验」已废） |
| 术语基准源 | PRD 内术语表/词汇表 → PRD 内首次定义处 → 记「建议补充术语表」不判错；不引入 PRD 之外标准 |
| 修改方向 | 每条问题必带：改哪个概念 / 哪句话、往哪改；只给方向不代写 PRD（模板「建议方向」列） |
| 评审任务清单 | `.spec/需求评审/任务清单.md` 单一事实源（待确认→已确认→已修复/已忽略） |
| 修复判据 | 修到什么表现算完成 |
| 分级冻结 | P0/P1 阻断，P2 留后续 |
| 复核只验本轮 | 不无限新增同级问题 |
| 轮次上限 3 | 不收敛停循环交用户 |
| 成因必写 | 推不出标成因未明，禁臆造 |
| 共性问题 | 多角色命中 = 系统性缺陷，标命中角色 |
