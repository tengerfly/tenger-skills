# CONTEXT.md —— PRD-Review 术语与决策记录

> PRD-Review 的术语对齐源与决策日志。

## 一、角色与边界

- 人设：前端/后端/测试三方评审组。
- 目标：找 PRD「逻辑不通、无法落地」的点。
- 边界：只审不改；无 Pass/Fail；修改经任务清单交 PRD-Design。

## 二、术语表

| 术语 | 定义 |
|---|---|
| 三角色评审立场 | 三专家各自唯一标准，独立成文，汇总才合并 |
| 评审任务清单 | `.spec/需求评审/任务清单.md` 单一事实源（待确认→已确认→已修复/已忽略） |
| 修复判据 | 修到什么表现算完成 |
| 分级冻结 | P0/P1 阻断，P2 留后续 |
| 复核只验本轮 | 不无限新增同级问题 |
| 轮次上限 3 | 不收敛停循环交用户 |
| 成因必写 | 推不出标成因未明，禁臆造 |
| 共性问题 | 多角色命中 = 系统性缺陷，标命中角色 |
