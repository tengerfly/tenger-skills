# 测试专家评审检查清单

> 标准：能否照 PRD 直接写可执行测试。只关心可测性/覆盖/追溯/歧义；不关心实现、布局、服务端技术。

| # | 维度 | 不通畅情形 |
|---|---|---|
| TE-1 | 验收可测性 | 需求无验收；验收是描述性文字无法执行；缺关键断言 |
| TE-2 | 验收质量（Gherkin） | Given/When/Then 缺段；Then 断言实现细节或无法量化；未标优先级 |
| TE-3 | 覆盖完整性 | 缺边界用例（0/超长/超限）；缺异常用例（失败/中断/越权/重复）；关键分支漏测 |
| TE-4 | 可追溯性 | 有需求无验收；孤儿验收；编号链断裂 |
| TE-5 | 可量化性 | 「尽量快 / 较多」等不可量化词；阈值 / 上限 / 次数未量化；TBD 未决项阻断测试（术语与文案表述问题归产品专家 `product-checklist.md` PM-3，此处不重复记录） |
| TE-6 | 可执行性 | 断言靠主观；Given 不可构造；引用未定义对象/状态 |
