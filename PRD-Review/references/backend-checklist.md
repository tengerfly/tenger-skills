# 后端开发专家评审检查清单

> 标准：能否照 PRD 独立完成服务端与数据设计。只关心业务对象/数据规则/状态机/异常边界/一致性；不关心控件、视觉、测试用例。

| # | 维度 | 不通畅情形 |
|---|---|---|
| BE-1 | 业务对象完整性 | 对象出现但属性/状态/生命周期未定义；流程用到未定义对象；核心状态缺失 |
| BE-2 | 数据规则 | 字段含义含糊；规则缺失（单位/精度/长度/范围）；上限阈值未定义且未标【设计假设】 |
| BE-3 | 状态机闭环 | 死循环；无终态；流转无触发条件；非法逆向未定义（判 P0） |
| BE-4 | 异常与边界 | 并发/重复提交、越权、超限、空数据、中断失败的幂等与处理未定义 |
| BE-5 | 数据口径一致性 | 同一指标 / 字段口径在不同模块定义不同；单位、精度、枚举值冲突；跨模块数据来源未指明（命名与术语不一致归产品专家 `product-checklist.md` PM-2，此处不重复记录） |
| BE-6 | 越界提醒 | 写了字段类型/索引/API/错误码/技术选型（标越界，评审侧通常 P2；流入 PRD 后产出方按其红线 4 判 P0，修复优先级以 PRD-Design 口径为准） |
