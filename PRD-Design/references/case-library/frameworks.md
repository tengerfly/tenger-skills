# 产品方法论框架速查（Frameworks）

> 用途：澄清需求、排优先级、定边界时的弹药库。每个框架给「一句话 + 适用 + 关键步骤/公式 + 反模式」。完整 77 框架见 deanpeters/Product-Manager-Skills。

---

## 一、优先级（排「先做什么」）

| 框架 | 一句话 | 公式/步骤 | 反模式 |
|---|---|---|---|
| RICE | 四因子量化排期 | Reach×Impact×Confidence÷Effort | 各因子拍脑袋，无来源 |
| ICE | 三因子快速打分 | Impact×Confidence×Ease | 单维度主导 |
| Kano | 功能分魅力/期望/必备/无差异/反向 | 问卷二维归类 | 把必备功能当亮点 |
| MoSCoW | Must/Should/Could/Won't 四分 | 四档归类 | Could 塞太多 |
| Value vs Effort | 价值-成本四象限 | 四象限矩阵 | 只看价值不看成本 |
| WSJF | 加权最短作业优先 | (业务价值+时间紧迫+风险降低)÷作业规模 | 分母估不准 |

## 二、用户研究（搞清「为谁解决什么」）

| 框架 | 一句话 | 关键点 |
|---|---|---|
| JTBD | 用户「雇佣」产品完成某个「任务」 | 功能 vs 情境 vs 结果三层 |
| Forces of Progress | 拉向新方案 vs 拽住旧习惯的两股力 | 焦虑/习惯是拽力 |
| Persona | 用户画像 | 基于真实调研，非拍脑袋 |
| Mom Test | 访谈时避免诱导式提问 | 问过去事实，不问未来意向 |

## 三、发现 / 验证（从机会到实验）

| 框架 | 一句话 | 关键点 |
|---|---|---|
| Opportunity Solution Tree（OST） | 从目标反推机会→方案→实验 | 先机会后方案 |
| Continuous Discovery | 持续对话用户而非一次性调研 | 每周对话 |
| Design Thinking / Double Diamond | 发散→收敛 两阶段 | 先想全再收敛 |

## 四、战略（定方向）

| 框架 | 一句话 | 关键点 |
|---|---|---|
| North Star Metric | 单一北极星指标 | 输入指标 vs 输出指标 |
| OKR | 目标+关键结果 | KR 可量化 |
| SMART | 目标五要素 | 具体/可衡量/可达/相关/有时限 |
| Blue Ocean | 避开红海创造新市场 | 价值创新 |
| Cynefin | 问题域分类（简单/复杂/混沌） | 先判域再定打法 |

## 五、增长 / 度量（看成效）

| 框架 | 一句话 | 关键点 |
|---|---|---|
| AARRR | 海盗指标：获客/激活/留存/营收/推荐 | 漏斗逐层 |
| HEART | Google 体验度量：幸福/参与/采纳/留存/任务成功 | 与业务目标对齐 |
| KPI | 关键绩效指标 | 输入/输出/护栏三类 |

## 六、商业模式（画商业逻辑）

| 框架 | 一句话 |
|---|---|
| Lean Canvas | 精简一页商业模式（问题/方案/独特卖点/渠道/收入/成本） |
| Business Model Canvas | 九宫格商业模式 |
| Value Proposition Canvas | 价值主张与客户痛点/收益匹配 |
| Impact Mapping | 目标→角色→影响→交付物 |

## 七、规划（排节奏）

| 框架 | 一句话 |
|---|---|
| Story Mapping | 用户故事地图，横轴流程纵轴优先级 |
| Roadmap（Now/Next/Later） | 三栏路线图 |
| Shape Up | Basecamp 六周周期，固定时间可变范围 |

## 八、需求分析（想透需求）

| 框架 | 一句话 |
|---|---|
| 5W2H | What/Why/Who/When/Where/How/How much |
| DHM | Delight 愉悦 / Hard-to-copy 难复制 / Margin-enhancing 提毛利 |
