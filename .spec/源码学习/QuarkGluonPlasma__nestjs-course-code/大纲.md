## 精读案例功能点清单（锚点）

### 章1 aop-test
- 一个 controller 同时挂 UsePipes/UseGuards/UseInterceptors/UseFilters（app.controller.ts:8-25）；五个组件文件（log.middleware/login.guard/time.interceptor/validate.pipe/test.filter）
- 讲解点：请求生命周期中各件的位置（对照 recipe 导读的生命周期图落地）

### 章2 认证与权限
- RequireLogin/RequirePermission = SetMetadata（custom-decorator.ts:3-5）
- LoginGuard：Reflector 读元数据→jwt verify→挂 request.user（login.guard.ts:31-53；express Request 类型扩展 :8-15）
- PermissionGuard：用户→角色→权限聚合 + getAllAndOverride 读类/方法两级元数据 + 逐项校验（permission.guard.ts:25-47）
- 实体三层：User↔Role↔Permission 多对多（user.entity.ts:25-26、role.entity.ts:20-21 JoinTable；permission.entity.ts:4-17）
- 双 token：login 签发 access+refresh 两种有效期（user.controller.ts:13-33）；/refresh 校验并双发（:37-62）
- 索引：redis-session-test/email-login-backend/qrcode-login/acl-test/single-token-refresh

### 章4 通信与异步
- rabbitmq-test/src：原生 amqplib，direct/fanout/topic/headers 四种交换机各有 producer+consumer（direct.js/direct-consumer1.js 等）
- microservice：user 服务 createMicroservice+Transport.TCP（microservice-test-user/src/main.ts:6-9）；main 服务 ClientProxy.send('sum')（microservice-test-main/src/app.controller.ts:15,22）
- schedule-task：cron + SchedulerRegistry 运行时增删定时任务（app.module.ts:23-33）
- cache-manager-test：CacheModule.register(Redis) + 自定义 MyCacheInterceptor（app.module.ts:10；app.controller.ts:37）
- 索引：chat-room-backend/sse-test/event-emitter-test
