# 浏览器审批与截图指引

> 环境预检 → 工具选择 → 无工具不工作。

## 一、检测顺序（能力检测，不穷举）
1. Playwright → 可用则打开原型截图。
2. browser-use → 可用则替代 Playwright。
3. 其他浏览器工具（agent-browser 等）→ 可用则使用。
4. 全不可用 → ⛔ 报错停止，不产出评审文档。

## 二、截图规范
- 只对 P0/P1 关键缺陷截图；纯文案/字段差异用代码行号比对，不截。
- 存 `.spec/原型评审/screenshots/`，命名 `ISSUE-[编号]-[页面]-[问题].png`。
- 报告中用相对路径内嵌：`![缺陷截图](./screenshots/...)`。

## 三、硬门禁失败
- 立即停止，不产出报告/任务清单。
- 明示：【环境错误】未检测到任何可用浏览器工具，原型评审硬依赖截图走查与存证，请安装后重跑。
- 静态源码审查是并行互证手段，不是缺工具时的替代。
