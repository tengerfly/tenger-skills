# 页面与载体完整性检查清单（Page Completeness Checklist）

> 目标：确保 PRD 中定义的所有模块、页面、视图及交互载体在原型中完整呈现，无遗漏、无静默裁剪，载体形态契合设计约定。

---

## 一、页面与模块映射覆盖度

### 1.1 PRD 页面清单对照
- [ ] **全量覆盖核对**：PRD `页面视图.md` 或各模块规格中列出的全部页面，在原型目录中必须有对应承载（独立 HTML 文件、明确的 Modal/Drawer 或内嵌区块）。
- [ ] **静默遗漏排查**：核查是否有「边缘页面」（如：404/500错误页、空数据指引页、操作历史页、权限不足提示页、个人资料设置页）被遗漏。
- [ ] **模块归属核对**：每个页面呈现的功能内容是否完全包含对应 PRD 模块定义的职责范围，未出现「模块在 PRD 存在但在原型任何角落都找不到」的情况。

### 1.2 信息载体形式合规（独立页 vs 弹框 vs 抽屉 vs 页内区块）
- [ ] **载体约定对照**：对照 Prototype-Design 前置确认的 `页面清单.md`：
  - 标记为【独立页面】的，必须有独立的 `.html` 文件；
  - 标记为【弹框 Modal】或【抽屉 Drawer】的，必须内嵌在其宿主页面中，**严禁单独建成独立 HTML**；
  - 标记为【页内区块 Section】的，必须在宿主页面相应位置完整展示。
- [ ] **载体合理性审核**：
  - 高频、轻量配置或简要确认操作是否误做成了跳转新页面；
  - 重度业务流程（如多步长表单、复杂大图表）是否误塞入了过小的弹框导致体验崩坏。

---

## 二、导航与结构完整性

### 2.1 全局导航与面包屑
- [ ] **导航菜单对齐**：原型中的顶部导航/侧边栏导航条目，其文案、层级、分组是否与 PRD 的信息架构图/页面清单一致。
- [ ] **面包屑导航路径**：深层详情页的面包屑路径是否完整，能否逐级点击返回父级页面。
- [ ] **默认激活态高亮**：进入各页面时，侧边栏或顶部导航的 Active 高亮项是否正确指向当前页面或模块。

### 2.2 视图模式与权限角色差异
- [ ] **多角色视角覆盖**：若 PRD 明确定义了不同角色（如：管理员 vs 普通用户、买家 vs 卖家）的不同视图，原型是否有切换角色演示的机制或完整页面形态。
- [ ] **移动端/响应式形态**（若涉及）：若要求移动端或响应式，检查移动端导航菜单（如 Hamburger Drawer、底部 TabBar）是否完整。
