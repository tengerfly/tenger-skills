# 页面与载体完整性检查清单

## 一、映射覆盖
- PRD 速查表页面/视图或模块 §3.1 的全部页面都有承载（独立 HTML/Modal/Drawer/区块）。
- 边缘页不遗漏（404、空数据、历史、权限不足、设置）。
- 模块职责完整呈现，无「PRD 有、原型找不到」。

## 二、载体合规（对照布局清单）
- 独立页面 = 独立 html；Modal/Drawer 内嵌宿主、禁单独成页；区块在宿主对应位置。
- 高频轻量操作不做成跳页；重流程（长表单/复杂图表）不塞小弹框。

## 三、导航与权限
- 顶部/侧栏菜单与 PRD 导航一致；深层页面包屑可逐级返回；Active 高亮正确。
- 多角色视图有切换或完整形态；移动端导航（Hamburger/TabBar）完整。

## 四、防加戏
- 每个按钮/链接/操作有 PRD 出处；无未定义的统计卡/通知栏/推荐位。
- 装饰克制；操作入口不冗余。影响主流程或冲突 → P1；纯装饰 → P2。
