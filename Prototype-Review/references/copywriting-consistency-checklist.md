# 文案与字段一致性检查清单

> 对照物：PRD（先读速查表建索引，细节按锚点回原文）。目标：文字/标签/提示/列名/字段与 PRD 逐字一致，无占位文案。

| 类别 | 检查项 |
|---|---|
| 标题/CTA | 页面、卡片、弹框标题与 PRD 逐字一致；按钮语义严格区分（保存/提交、确认/确定、通过/驳回），不得用「OK/确定」替代具体动作 |
| Placeholder/反馈 | 占位符体现格式要求，禁 input text here；成功/失败提示与 PRD 一致；破坏性操作确认文案含后果警告 |
| 表单字段 | Label 与 PRD 一致；必填有星号、选填不误标；选项枚举完整；控件类型与规格匹配（单选/下拉/日期区间/金额单位） |
| 表格 | 列名与顺序符合 PRD；状态文案与状态机枚举相同；状态配色符合通用认知；Mock 数据字段自洽（时间/金额逻辑正确） |
| 冗余文案 | PRD 未定义的 Toast/引导/说明/CTA 记为冗余；与 PRD 冲突或误导记 P1，纯多余记 P2 |
