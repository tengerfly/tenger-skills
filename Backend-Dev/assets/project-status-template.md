## 4. 项目规则（开发时必须遵守）

- **分层**：Controller → Service → Repository → Entity，依赖单向向下，禁跨层；
- **命名**：业务语言、语义化，禁魔法值（状态/枚举/错误码常量化）；
- **注释**：讲「为什么」，方法有传参必写参数作用；
- **错误处理**：统一响应 `{code,message,data}`，错误码分段，不吞异常；
- **提交**：功能点提交 + eslint/commitlint 校验 + Conventional Commits；
- **接口契约**：共享 DTO 放 `libs/shared`，前后端单一事实源。
