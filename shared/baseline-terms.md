# 双基准术语（公共约定）

> 本文件是双基准术语的集中定义源（根 README 等处按此引用）。谈结构用「低保真原型」，谈视觉用「设计稿」；两词不得混用，旧称不得残留于现行正文（历史决策记录除外）。

| 术语 | 定义 | 边界 |
|---|---|---|
| 低保真原型 | Prototype-Design 产出，落 `.spec/原型/`；极简中性色 + 单一主色 + 基础字号层级，可点可交互；载体划分先经布局清单 Gate（产 `布局清单.md`） | **结构基线**：页面/载体结构、交互流转的唯一结构真相源；不是高保真稿，也不是纯灰白线框 |
| 设计稿 | UI-UX-Design 产出，归档 `.spec/设计稿/`（CLI 工作目录 `.superdesign/`）；以 design-system.md 为规范源 | **视觉基准**：色值/字号/间距等视觉值以 design-system token 为权威；⑥⑦ 为可选节点，缺失时视觉基准回退低保真原型 + 用户确认 |

## 引用规则

- 布局/结构/载体/流转 → 依据**低保真原型**（+ 布局清单）。
- 视觉值/组件样式/状态视觉 → 依据**设计稿**（+ design-system.md）；无设计稿时从原型基础值收敛，经用户确认。
- 废弃旧称：`高保真原型`、`页面视图清单`、指 Prototype 产物时的`页面清单`/`wireframe`——现行术语一律用上表。

## 消费方速查
