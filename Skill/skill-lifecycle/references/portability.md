# 独立使用、复制与分享

## 使用环境

本包运行规则只要求助手能读取本地 Markdown，并在用户授权目录写入文件；并不自带模型或文件权限。没有 Python 仍可按规则工作，但不能声称执行了脚本校验。可选脚本需要 Python 3.10+ 标准库，不调用其他 Skill、仓库脚本、服务或网络。

接收方可直接让助手读取本目录的 SKILL.md。若宿主支持 Skill 安装，可按宿主自己的机制加载整个 skill-lifecycle 目录；本包不指定客户端安装路径，不承诺自动发现，不自动写全局配置。只读安装目录适合放工具，运行数据必须另选可写位置。

## 三个目录，避免混在一起

- **本工具包**：可重复分享的通用方法与空白模板，默认不在运行中改写。
- **目标源码**：用户创建/接管的 Skill 入口、references、assets 和必要 scripts。
- **维护目录**：context.md、issues、preferences.md、cases.md、iterations/（方案、快照、验证记录）。按用户/目标隔离，目录互不包含，不随工具包分享。

这些位置首次登记在 context.md。没有路径信息时先确认或使用已授权任务摘要，不能按固定磁盘位置、上两层目录或当前工作目录猜原作者源仓。

## 分享工具包

复制完整 skill-lifecycle 目录即可，本包内的规则、脚本、测试和模板都是发布内容；执行产生的 __pycache__/、.pyc 不是发布内容，复制时排除（缓存可能保留本机路径）。运行维护记录不应放这里；若接收方已经往包内塞入日志、密钥或个人数据，分享前必须先检查移除，脚本不会替你做语义隐私审查。

## 分享最终目标 Skill

1. 先确认分享的是“通用版”还是“保留哪些偏好的个人版”，列文件清单。仅在新的导出目录操作，拒绝覆盖已有目录，不修改原源码。
2. 根据入口引用与运行行为核对需要的 references/assets/scripts，以及依赖声明。保留真正必要资源，不只拿 SKILL.md，也不把整个维护目录一起复制。
3. 清除问题详情、聊天原文、快照、日志、Token、私人路径和客户数据；案例改用合成数据。移除指向原作者维护目录的配置，反馈钩子保留通用路径选择规则。通用版移除个人偏好及对应引用；个人版仅保留获准内容。
4. 外部工具/网络确实属于目标能力时，明确先决条件与缺失处理；不宣称任何环境都能独立执行。外部引用文件需要授权后内置，或明确列依赖，不能伪装已打包。
5. 在与源仓无关的临时目录仅用导出文件运行结构检查和可用行为场景。缺文件、路径越界、工具不可用要报告，不临时从原仓借文件掩盖问题。
6. 提供目标用途、触发示例、依赖、反馈记录方式、版本、验证范围。交付是复制文件，不是已经安装到接收方环境。

本包不导出或自动上传任何内容；上述操作由助手在用户明确要求分享后执行。结构检查不包含秘密扫描，不保证任意动态代码依赖都能静态识别。
