# 专项测试指南（L4：负载/压力/稳定 + 安全 + 兼容/无障碍）

> 信号触发，默认不跑。功能问题找 L0-L3，本层回答「扛不扛得住、安不安全、 everyone 能不能用」。

## 一、何时触发（需求信号 → 专项）

| 信号（PRD/用户话语关键词） | 专项 | 缺省工具 |
|---|---|---|
| 高并发 / 大流量 / 性能要求 / 压测 / 卡不卡 | 负载/压力/稳定 | k6（零依赖时 Node fetch 并发脚本兜底） |
| 敏感数据 / 对外接口 / 支付 / 合规 / 安全 | 安全扫描 | pnpm audit + Semgrep 快扫 +（可选）OWASP ZAP baseline |
| 多端 / 多浏览器 / 兼容性 | 兼容矩阵 | Playwright 多内核（chromium/firefox/webkit） |
| 无障碍 / 适老化 / 政务项目 | 可访问性 | axe-core 注入扫描 |
| 涉 AI 生成功能 | AI 输出评估 | promptfoo（LLM 输出回归） |

## 二、负载/压力/稳定测试（四段模型）

按成本升序执行，任一段指标爆表即停（再压无意义）：

| 段 | 目的 | 模型（无 PRD 阈值时的【设计假设】缺省） |
|---|---|---|
| **Smoke 冒烟** | 脚本能跑、基线吞吐 | 2-5 并发 × 1 分钟 |
| **Load 负载** | 预期峰值下指标达标 | 预期峰值并发（无依据按 20-50）× 3-5 分钟，斜坡上升 |
| **Stress 压力** | 找拐点与失败形态 | 并发阶梯递增（每级 +50%，每级 1 分钟）直到错误率 >5% 或 P95 >5s |
| **Soak 浸泡** | 内存泄漏/连接堆积 | 峰值 30% 并发 × 30 分钟+（夜间/CI 定时跑） |

**指标与缺省阈值（【设计假设】可调）**：
- P95 延迟 < 1000ms、P99 < 3000ms（API）；页面加载 LCP < 2500ms
- 错误率 < 1%（非 4xx 业务错误；5xx/超时/连接拒绝都算）
- 吞吐（RPS）记录基线：Load 段相对 Smoke 段增幅 < 并发增幅的一半 = 出现瓶颈，记 P2
- Stress 段观察**失败形态**：优雅降级（429/排队）✓ vs 崩溃/数据损坏 ✗（后者 P0）

**测什么接口**：主链读接口（列表/详情）+ 1-2 个写接口（注意写压测会造脏数据——沙箱内跑、跑后清数）；**禁压外部第三方**（LLM API 等，只压被测系统自身）。

**AI 生成代码的高频性能坑（压测重点盯）**：列表无分页全量拉取、N+1 查询、同步阻塞外部调用、无连接池、内存内聚合大结果集、缺索引全表扫。

## 三、安全扫描（三档）

| 档 | 内容 | 工具 | 何时 |
|---|---|---|---|
| 快扫（每次大版本） | 依赖漏洞审计 | `pnpm audit` / `npm audit --production` | L0 之后即可 |
| SAST 快扫 | 注入/XSS/硬编码密钥/危险函数 | Semgrep（`semgrep --config auto`）或人工检查点清单 | 信号触发 |
| DAST（可选） | 运行态扫基线漏洞 | OWASP ZAP baseline scan | 对外系统才做 |

**AI 生成代码的高频安全坑（人工检查点清单）**：SQL/命令拼接注入、用户输入未转义直接渲染（XSS）、API Key/密码硬编码或入日志、接口无鉴权/越权（IDOR：改 URL 里的 id 就能看别人数据）、文件上传不校验类型/路径穿越、CORS 全开 `*`。

## 四、兼容矩阵与无障碍

- **兼容**：按用户画像选内核组合（缺省 chromium + webkit；政务/企业加 firefox），L2 用例库抽 P0 用例在多内核重放即可，不必全量；
- **无障碍**：axe-core 注入每关键页扫一遍，critical/serious 违规记 P2（colour-contrast、缺少 alt、键盘不可达是 AI 生成页面三大高频项）；
- **数据强度**：构造大数据量页面（如 1000 行列表）验证渲染与滚动性能——AI 生成页面常见「开发时 10 条数据很流畅，上线 1000 条卡死」。

## 五、结果处理

- L4 结果**只分级报告不阻断**（除 Stress 段出现数据损坏/崩溃/错误率爆表 = P0 阻断）；
- 指标表进报告专项节（见 report-template），每项给「阈值 vs 实测 vs 判定」；
- 未达标的专项给修复任务卡（如「列表接口 P95 2.3s 超阈值，建议加分页/缓存」）；
- Soak 类长时任务标记为夜间/CI 定时项，不阻塞交付。
