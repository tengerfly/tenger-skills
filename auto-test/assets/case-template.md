# 用例模板（三段式）

> 复制本模板创建 `用例库/TC-<模块>-<序号>.md`。编号规则：功能 `TC-<模块>-<序号>`；样式 `TC-<页面>-样式-<序号>`；接口 `TC-接口-<序号>`。

```markdown
# TC-<模块>-<序号>：<一句话标题>

| 字段 | 内容 |
|---|---|
| 模块/页面 | {{页面名}} |
| 状态机节点 | {{状态} → {{迁移后状态}}（无状态机则填页面清单条目） |
| 关联基准 | {{AC-Mxx-nnn / 设计稿页面 / 接口路径}} |
| 优先级 | P0 / P1 / P2 |

## setup（状态注入，机器可执行）
- seed: {{API 造数 / DB 种子命令}}
- state: {{storageState 文件（如需登录态）}}
- mock: {{外部依赖 → 预期行为}}
- intercept: {{路由拦截 → 异常注入}}（按需）

## act（操作步骤）
1. {{步骤}}
2. {{步骤}}

## assert（断言，预期必须有来源）
- aiAssert: {{视觉断言（对照设计稿/AC 自然语言描述）}}
- expect: {{URL / DOM / 状态断言}}
- network: 全部响应 200、无 console error、慢接口阈值内
- 覆盖: [{{状态}}, {{状态→状态}}]

## 执行回填
| 轮次 | 结论 | 证据 | 备注 |
|---|---|---|---|
| run-{{日期}}-R{{n}} | Pass/Fail/Blocked | {{截图/console/网络路径}} | {{备注}} |
```

**自检六问**（写完必过，来自 case-authoring-guide §六）：状态对应真实节点 / setup 可机器执行 / 断言有来源 / mock 显式且不碰业务逻辑 / coverage 已填 / 可独立重跑。
