## 三、用例编号规则

- 功能：`TC-<页面/模块>-<序号>`；
- 样式：`TC-<页面>-样式-<序号>`；
- 接口性能：`TC-接口-<序号>`；
- 来源标注：功能用例尽量标注 PRD 的 `AC-Mxx-nnn`；样式用例标注原型页面；接口用例标注后端 TDD 接口路径。

## 四、优先级定义

| 优先级 | 含义 |
|---|---|
| P0 | 核心流程 / 阻断性功能 / 全状态主链路，必须测 |
| P1 | 主要功能 / 次按钮点击 / 主要页面样式 / 主要接口性能 |
| P2 | 次要样式 / 文案 / 体验优化 / 非核心接口 |
