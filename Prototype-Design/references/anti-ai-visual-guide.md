# 反 AI 味视觉规范

> 目标：让生成的 HTML 原型像**真实设计师的手笔**，而不是"一眼 AI"的模板产物。

---

## 一、什么是"AI 味"（典型症状）

AI 生成的界面往往有以下可识别的"模板感"：

1. 紫罗兰 → 靛蓝的渐变背景铺满 hero 区；
2. emoji 当图标（🚀📊✨🔥）；
3. "大标题 + 三张卡片 + 一个按钮"的固定 hero 结构；
4. 漂浮的模糊光斑 / blob / 渐变圆球做装饰；
5. 卡片阴影过重，或过度使用玻璃拟态；
6. 大面积留白，内容密度低到不像真实产品；
7. 配色永远是"安全蓝"，缺乏产品个性；
8. 字体单一，标题正文一个字号字重。

---

## 二、负面清单（禁止）与替代做法

| # | ❌ 禁止 | ✅ 替代做法 |
|---|--------|-----------|
| 1 | emoji 当图标 | 用内联 SVG 简洁图标，或纯文字标签 |
| 2 | 紫→蓝渐变默认背景 | 从产品定位推导主色；背景用纯色 / 浅灰 / 克制渐变 |
| 3 | 装饰性光斑 / blob 背景 | 用真实的信息结构填充，不做无意义装饰 |
| 4 | hero 大标题 + 三卡片模板 | 布局贴合真实产品信息架构（导航 / 列表 / 表单 / 详情） |
| 5 | 卡片阴影过重、玻璃拟态泛滥 | 阴影克制（`0 1px 3px rgba(0,0,0,.08)` 级别），玻璃拟态仅在必要时用 |
| 6 | 大面积留白、内容空洞 | 信息密度贴近真实应用，该有的列表 / 数据 / 操作都放上 |
| 7 | 默认"AI 蓝"配色 | 按 `style-catalog.md` 匹配定位，选有产品个性的配色 |
| 8 | 字体单一无层级 | 标题 / 正文 / 辅助三级字号与字重分层（如 28/16/13px） |

---

## 三、正反例对照

### ❌ AI 味（反面）
```html
<!-- 紫蓝渐变 + emoji + 光斑 + 三卡片 -->
<div style="background:linear-gradient(135deg,#7c3aed,#2563eb)">
  <h1>🚀 让学习更高效</h1>
  <div class="cards">
    <div class="card">📚 计划</div>
    <div class="card">📊 进度</div>
    <div class="card">✨ 反馈</div>
  </div>
</div>
```

### ✅ 去 AI 味（正面）
```html
<!-- 贴合定位的纯色头部 + SVG 图标 + 真实信息结构 -->
<header style="background:#0f766e;color:#fff">
  <nav>学习计划 / 我的课程 / 进度</nav>
</header>
<main>
  <section class="plan-list">
    <div class="plan-item">
      <svg><!-- 日历图标 --></svg>
      <span>高一数学 · 第 3 周计划</span>
      <span class="badge">进行中</span>
    </div>
  </section>
</main>
```

## 四、自检清单（生成后逐条过）

- [ ] 全篇无 emoji 图标，图标均为 SVG 或文字；
- [ ] 无紫→蓝渐变默认背景，无光斑 / blob 装饰；
- [ ] 布局贴合真实产品信息架构，非 hero + 三卡片模板；
- [ ] 阴影克制，无过度玻璃拟态；
- [ ] 信息密度真实，无大面积空洞留白；
- [ ] 配色有产品个性，非默认 AI 蓝；
- [ ] 字体有三级层次（标题 / 正文 / 辅助）。

> 任一命中即返工，直到全绿。
