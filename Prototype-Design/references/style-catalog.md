# 风格基因库与「定位 → 风格」匹配规则

> 用途：为风格澄清阶段提供素材，让 AI **基于产品定位动态生成**三套差异化方案，而不是套固定模板。

---

## 一、风格基因（原子要素）

每套方案由以下四类基因组合而成，组合方式决定视觉气质：

### 1. 配色基因

| 配色气质 | 主色方向 | 中性色 | 适配产品 |
|---------|---------|--------|---------|
| 克制专业 | 藏蓝 / 深青 / 石墨灰 | 冷灰系 | 效率工具、B2B、金融、医疗 |
| 活泼亲和 | 珊瑚橙 / 明黄 / 鲜绿 | 暖灰 + 白 | 社交、消费、教育、社区 |
| 沉稳商务 | 深蓝 / 墨绿 / 酒红 | 中性灰 | 企业级、管理后台、政务 |
| 科技未来 | 深空黑 + 荧光点缀 | 深灰 | 硬核科技、开发工具、AI 产品 |
| 清新自然 | 松石绿 / 雾蓝 / 燕麦 | 米白 | 健康、生活方式、母婴 |

### 2. 排版基因

| 排版气质 | 字体层级 | 密度 | 圆角 |
|---------|---------|------|------|
| 精致轻盈 | 大字号标题 + 细字重 | 宽松 | 大圆角（12~16px） |
| 实用紧凑 | 中等字号 + 层次分明 | 紧凑 | 小圆角（4~8px） |
| 稳健平衡 | 常规字号 + 清晰层级 | 适中 | 中圆角（8~12px） |

### 3. 交互模式基因（布局 / 导航）

| 交互模式 | 结构特征 | 适配产品 | 适配端 |
|---------|---------|---------|--------|
| 顶部 Tab + 内容流 | 顶部导航、内容纵向滚动 | 内容型 / 信息流 | Web / 移动 |
| 底部 Tab + 分栏 | 底部固定导航（移动端心智） | C 端 App 类、工具类 | 移动 |
| 侧边栏 + 工作区 | 左侧导航、右侧内容区 | B2B、后台、SaaS | Web |
| 列表—详情纵深 | 列表页 → 详情页层层下钻 | 交易、订单、库存 | Web / 移动 |

### 4. 气质基因（整体观感）

| 气质 | 关键词 | 视觉特征 |
|------|-------|---------|
| 克制 | 留白、秩序、少即是多 | 弱对比、细线条、大面积留白 |
| 活泼 | 亲和、明快、有能量 | 高饱和点缀色、圆润、动感图标 |
| 商务 | 专业、可信、稳重 | 深色导航、紧凑信息、蓝灰主调 |

---

## 二、三套方案生成法（基于定位）

**步骤**：
1. 从 PRD 提取：产品一句话定位 + 目标用户 + 核心使用场景；
2. 选定一个"主气质"（最匹配定位的），再选两个"差异化对照气质"（气质必须真实不同）；
3. 为每个气质组合出完整的「配色 + 排版 + 交互模式 + 适用理由」。

**差异化铁律**：三套方案在**视觉气质**上必须有真实区分（如「克制专业 / 活泼亲和 / 沉稳商务」），绝不能只是换个主色。若三套看起来雷同，即视为不合格。

**示例**（以"AI 学习助手"为例）：
- 方案 A「清新学习风」：松石绿主色 + 宽松排版 + 底部 Tab，理由——贴合年轻学生、亲和鼓励学习氛围；
- 方案 B「专注效率风」：藏蓝主色 + 紧凑排版 + 顶部 Tab，理由——突出学习计划与专注，工具感强；
- 方案 C「沉稳专业风」：深蓝主色 + 适中排版 + 侧边栏，理由——若面向机构/家长，体现可信与规范。

---

## 三、适配速查（定位 → 主气质倾向）

| 产品类型 | 主气质倾向 | 交互模式倾向 |
|---------|-----------|-------------|
| 效率 / 工具 / 生产力 | 克制专业 | 顶部 Tab / 侧边栏 |
| C 端社交 / 消费 / 社区 | 活泼亲和 | 底部 Tab |
| 企业 / 后台 / 政务 | 沉稳商务 | 侧边栏 + 工作区 |
| 交易 / 订单 / 库存 | 克制专业 | 列表—详情纵深 |
| 健康 / 生活方式 / 母婴 | 清新自然 | 顶部 Tab / 内容流 |
| 硬核科技 / 开发工具 | 科技未来 | 侧边栏 / 顶部 Tab |

> 速查表只是**起点倾向**，最终方案仍以 PRD 真实定位为准，可跨格组合。

---

> **衔接**：用户选定方案后，不要直接画页面，先把选定方案展开为完整样式规范（Design Tokens + 组件规范，模板见 `assets/style-guide-template.md`），经用户确认后再进入页面设计。
