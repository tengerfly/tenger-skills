# HTML 原型实现规范

> 用途：规定 HTML 原型的文件组织、跳转方式、设计 token、可点击交互，保证产出可运行、风格统一。

---

## 一、文件组织

- 每个独立页面一个 HTML 文件（以步骤 3 信息载体确认 Gate 的清单为准），命名语义化：`index.html`（入口）、`list.html`、`detail.html`、`publish.html` 等；
- 弹框 / 抽屉 / 页内区块**不单独成文件**，内嵌在宿主页面中实现（原生 JS 控制显隐）；
- 所有文件放在 `.spec/原型/` 同一目录下，便于相对路径跳转；
- 附一个 `README.md` 说明页面清单与跳转关系。

## 二、页面间跳转（可点击闭环）

- 用真实 `<a href="detail.html">` 链接实现跳转，禁止用无意义的 `#` 占位；
- **闭环要求**：每个页面都要能"进来"（有入口链接指向它）且能"出去"（有返回 / 下一步链接），断头或孤立页面即缺陷；
- 列表项、按钮、卡片等可点击元素，都接真实链接或说明跳转目标。

## 三、设计 token（CSS 变量统一风格）

每个 HTML 文件顶部用同一套 CSS 变量定义 token，保证配色 / 字号 / 间距全站一致：

```css
:root {
  /* 配色（按选定方案） */
  --color-primary: #0f766e;      /* 主色 */
  --color-primary-dark: #115e59; /* 主色深 */
  --color-accent: #f59e0b;       /* 点缀 */
  --color-bg: #f8fafc;           /* 背景 */
  --color-surface: #ffffff;      /* 卡片 / 面 */
  --color-text: #0f172a;         /* 正文 */
  --color-text-secondary: #64748b;/* 辅助文字 */
  --color-border: #e2e8f0;       /* 描边 */
  /* 语义色 */
  --color-success: #16a34a;
  --color-warning: #d97706;
  --color-danger: #dc2626;
  /* 字号层级 */
  --font-title: 28px;
  --font-body: 16px;
  --font-caption: 13px;
  /* 圆角 / 间距 */
  --radius: 8px;
  --gap: 16px;
}
```

- 所有页面共用同一份 token，禁止各页各写各的配色。

## 四、可点击交互

- 静态可点击元素用 `<a>` 跳转页面；
- 页内交互（如 Tab 切换、弹层、表单校验提示）用少量原生 JS 实现，不引第三方框架；
- 交互要有真实反馈：按钮 hover / 点击后跳转或状态变化，不能是"死按钮"。

## 五、内容要求

- 界面文案用**真实业务文案**（来自 PRD 的需求描述），不用占位符 Lorem、不用"某某某""测试数据"式假文案，除非 PRD 未定义则用贴合定位的示例文案；
- 数据展示用贴近真实业务的数据（如真实感的列表项、金额、状态标签），体现"信息密度真实"；
- 图标用内联 SVG，不用 emoji（见 `anti-ai-visual-guide.md`）。

## 六、端类型布局规范（强制）

端类型在流水线步骤 2 与用户确认，决定页面布局规范：

| 端类型 | 视口 / 布局 | 导航交互 | 交付形态 |
|---|---|---|---|
| Web 端 | 桌面宽度（如 1280px 容器） | 侧边栏 / 顶部导航 | 单套 `*.html` |
| 移动端 | 375px 视口、触控间距 | 底部 Tab / 顶部返回 | 单套 `*.html` |
| 双端同步 | 由用户二选一（见下） | 各自按端匹配 | 见下 |

- **优先 Web 端**：用户未明确时，推荐并默认按 Web 端产出；
- **双端同步由用户选择，不代拍板**：
  - **两套独立原型**：Web / 移动各一套，交互与布局各自定制，交付 `web/` 与 `mobile/` 两个子目录；
  - **一套响应式布局**：同一套页面用媒体查询断点适配多端，交付单套 `*.html`；
- 移动端注意触控目标尺寸、底部 Tab 拇指区，Web 端注意信息密度与多栏布局。

## 七、交付自检

- [ ] 每个核心页面都有对应 HTML 文件；
- [ ] 页面间跳转闭环，无断链、无孤立页；
- [ ] 全站共用一套 CSS 变量 token，风格统一；
- [ ] token 与组件严格套用沉淀的 `style-guide.md`，无另起炉灶；
- [ ] 无 emoji 图标、无 AI 模板感（对照 `anti-ai-visual-guide.md` 自检清单）；
- [ ] 文案与数据真实可感，无 Lorem 占位。
