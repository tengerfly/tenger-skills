# 真实案例：AI 学习助手「学径」——「专注效率风」完整落地

> 本文档是一份**已交付的真实高保真原型案例**（学习资料导入 → 学习路线图 → 节点学习 → 自测 → 知识库 → 知识图谱），用于示范如何把「专注效率风」从一份风格方案，落地为一套可运行、可点击、去 AI 味的 HTML 原型。
>
> 适用复现场景：**任务型学习 / 效率工具 / 生产力类 Web 产品**。做同类产品原型时可直接以本案例为基线，替换业务内容即可。

---

## 1. 案例档案

| 项 | 内容 |
|---|---|
| 产品 | AI 学习助手「学径」（LearnPath） |
| 一句话定位 | 导入资料 → 生成学习路线图 → 学完自测 → 沉淀知识库 → 知识图谱，让学习更简单 |
| 目标用户 | 自学开发者 / 产品经理（主动学新领域，痛点是"收藏多、不知道从哪学、学完就散"） |
| 端类型 | Web 桌面端 |
| 选定方案 | 方案 A「专注效率风」 |
| 主气质 | 克制专业（弱对比、细线条、大面积留白、工具感强） |
| 交互模式 | **顶部导航 + 内容流**（用户明确否决了侧边栏，要求所有导航入口上移头部） |
| 核心页面 | 4 页：首页 / 学习页 / 知识库 / 知识图谱（其余流程用弹框承载，不单独成页） |

> **关键取舍**：一份资料 = 一张学习路线图，所以「资料库」并入首页，不单设列表页；「自测」全程在聊天流 / 弹框内完成，不跳独立页面。

## 2. 设计 Tokens（全站统一 `:root`）

```css
:root {
  /* 配色 —— 藏蓝主色 + 青绿辅色，克制专业气质 */
  --color-primary: #1E3A5F;        /* 主色 藏蓝 */
  --color-primary-dark: #152C4A;   /* 主色深（悬浮提示底） */
  --color-accent: #2C7A7B;         /* 辅色 青绿（进行中/可交互强调） */
  --color-accent-light: #E6F2F2;   /* 辅色浅底 */
  --color-amber: #D97706;          /* 琥珀（待沉淀/未掌握/待关联强调） */
  --color-amber-light: #FEF3E2;
  --color-bg: #F7F9FB;             /* 页面背景 冷灰 */
  --color-surface: #FFFFFF;        /* 卡片面 */
  --color-text: #1E293B;           /* 正文 */
  --color-text-secondary: #64748B; /* 辅助文字 */
  --color-text-inverse: #CBD5E1;
  --color-border: #E2E8F0;         /* 描边 */
  /* 语义色 */
  --color-success: #16A34A;
  --color-warning: #D97706;
  --color-danger: #DC2626;
  /* 字号层级 —— 三级分层，克制 */
  --font-title: 22px;    /* 页面标题 */
  --font-section: 16px;  /* 区块标题 */
  --font-body: 14px;     /* 正文 */
  --font-caption: 12px;  /* 辅助说明 */
  /* 圆角 / 间距 / 阴影 —— 小圆角、克制阴影 */
  --radius: 6px;
  --gap: 16px;
  --shadow: 0 1px 3px rgba(15, 23, 42, .08);
}
```

> 要点：小圆角（6px）、极轻阴影（单层 1px）、冷灰背景 `#F7F9FB` 与纯白卡片面，整体"少即是多"，贴合效率工具的克制气质。

## 3. 布局与页面结构（本案例的核心沉淀）

### 3.1 首页 `index.html` —— 居中落地页（无导航栏）

首页是"学习入口"，**刻意不放顶部导航**，用居中 Hero 聚焦主操作：

```
┌──────────────────────────────────────────┐
│          [Logo SVG]（约 48px）            │   ← 居中 Hero
│            学 径（h1，大字重）            │
│          让学习更简单（slogan，灰字）      │
│      [ ＋ 导入学习资料 ]（主按钮）          │
├──────────────────────────────────────────┤
│  最近学习                      最近 9 条   │   ← 区块标题行（左标题 + 右灰字辅助）
│  ┌────┐ ┌────┐ ┌────┐                    │
│  │卡片│ │卡片│ │卡片│   ← 3×3 九宫格        │
│  └────┘ └────┘ └────┘                    │
│      （超过 9 条时下方出现「更多」按钮）      │
└──────────────────────────────────────────┘
```

- **学习卡片**结构：来源徽标（GitHub / PRD）+ 状态徽标（进行中 / 待沉淀 / 已归档）→ 标题 → 进度条 → 一句统计（"已掌握 4/8 · 当前：Diff 算法"）→ 底部"时间 + 进入学习"；
- 卡片点击**直达学习页**（不做中转详情页）；
- 空态：无学习路线图时，居中引导导入第一份资料。

### 3.2 其余页面：顶部导航 58px（白底描边）

```
┌──────────────────────────────────────────────────┐
│ [Logo icon] 学径 · 让学习更简单   [icon][icon][icon] [头像] │  ← 58px 顶部导航
└──────────────────────────────────────────────────┘
│  内容工作区（padding 24px）                        │
```

- 左侧：Logo icon + 品牌名 + slogan；
- 右侧：三个模块 icon（首页 / 知识库 / 知识图谱，当前页高亮）+ 用户头像（hover 展开菜单进入「设置」）；
- 导航 icon 规格：38×38 圆角方块，默认灰字，悬停浅灰底，激活青绿浅底 + 青绿字。

### 3.3 学习页 `learn.html` —— 三栏布局（本案例最复杂的布局）

```
┌──────────┬───────────────────────────┬──────────┐
│ 学习路线图 │   对话区（AI 讲解 + 提问）  │ 溯源 · 原文│
│ 1..8 节点 │   ─────────────────────   │ 源码片段  │
│ （串行解锁）│   [自测题内嵌在对话流中]     │          │
│          │   ─────────────────────   │          │
│          │   [输入框 + 发送]           │          │
└──────────┴───────────────────────────┴──────────┘
左（窄，约 240px）   中（弹性）      右（约 320px，可收）
```

- **左栏（学习路线图）**：节点序号 + 状态点（已完成 / 未掌握 / 学习中 / 锁定）；虚线锁定节点不可点；已学完节点可点击回看；
- **中栏（学习过程）**：AI 与用户的聊天气泡流；**节点级自测内嵌在对话流中**（不是独立页面）；底部输入框；
- **右栏（溯源）**：展示当前节点对应的**源码/原文片段**，带行号；与对话中带虚线标记的文字联动定位；
- **综合自测全程弹框**：全部节点学完 → 系统弹「综合自测」弹框（确认 → 作答 → 结果 → 进入知识沉淀），不跳页。

### 3.4 知识库 `knowledge.html` —— 列表 + 筛选 + 详情弹框

```
│ [检索框 + 检索]                                  │
│ 标签: 全部/前端/后端/…    掌握状态: 全部/已掌握/未掌握  [列表/按记录分组] │
│ ┌────────────────────────────────────────────┐ │
│ │ 虚拟 DOM Diff 算法   [前端][算法]    vuejs/core [已掌握]│ │
│ │ LIS 移动优化        ...                     │ │
│ └────────────────────────────────────────────┘ │
```

- 列表以**知识点为单位**（一行一条知识点，可直接检索/筛选）；
- 行结构：标题 + 一句话描述 + 标签 + 来源 + 掌握状态徽标；点击弹详情；
- 详情弹框：标题 + 状态 + 标签 + 来源回溯（源码片段）+ 完整正文。

### 3.5 知识图谱 `graph.html` —— 标签 + 力导向 SVG 图谱

```
│ [前端][后端][数据库][架构][算法][AI]         [🔗关联(红点)] │  ← 标签与关联操作同行
│ ┌────────────────────────────────────────┐ │
│ │   力导向 SVG 图谱（节点可拖拽、点击弹详情）  │ │
│ │   已关联=实线 / 待关联=虚线 / 孤点=空心     │ │
│ └────────────────────────────────────────┘ │
```

- **标签芯片**承载分类（"前端 · 知识点 14 · 已关联 12 · 未关联 2"），点击切换该标签下的图谱；
- **关联入口**是右上角 icon（有待确认时红点提示数字，hover 显示"关联"），与标签同行；
- 图谱铺满屏幕、力导向动态布局；**节点单击弹详情、按住拖动调整布局**（二者用"是否位移超过阈值"区分）；
- 关联三态：已关联（实线绿）/ 待关联（虚线琥珀）/ 孤点（空心灰）。

## 4. 组件规范（复用基线）

### 4.1 按钮
- 主按钮：藏蓝底白字，圆角 6px，内距 `9px 16px`；
- 次按钮：白底 + 描边 + 正文色；文字按钮：青绿文字；
- 危险操作（取消关联等）：红字白底描边。

### 4.2 卡片
白底、6px 圆角、`0 1px 3px` 轻阴影、1px 描边。

### 4.3 状态标签（Badge）—— 语义色浅底 + 深字

| 状态 | 底色 | 文字 |
|---|---|---|
| 进行中 / 学习中 | `#E6F2F2` | `#2C7A7B` |
| 待沉淀 / 待关联 | `#FEF3E2` | `#B45309` |
| 已归档 | `#EEF2F6` | `#64748B` |
| 已掌握 / 已关联 | `#DCFCE7` | `#16A34A` |
| 未掌握 | `#FEE2E2` | `#DC2626` |

### 4.4 标签芯片（TagChip）
圆角胶囊，默认白底描边灰字；选中态藏蓝底白字。

### 4.5 进度条
8px 高圆角条，底 `#EEF2F6`，填充 藏蓝→青绿渐变。

### 4.6 聊天气泡（学习页）
AI 气泡白底描边，用户气泡藏蓝浅底；`<code>` 用等宽字体；关键词用高亮（`hl`）。

### 4.7 图标
全部内联 SVG 线性图标（1.6~1.8px 描边），禁 emoji。

## 5. 关键交互模式（含实现要点）

1. **头像 hover 菜单不"断链"**：菜单定位若与头像间留空隙，鼠标移向菜单时 `hover` 会失效。做法是给 `.avatar-wrap` 上下加 `padding` 撑出连续热区（与 58px 顶栏等高），菜单 `top:100%` 紧贴，并补 `.avatar-menu:hover` 双保险；
2. **图谱节点「点击 vs 拖拽」区分**：用 Pointer 事件记录按下位置，`pointermove` 位移超过阈值（SVG 坐标系约 4px）判为拖动，`pointerup` 时未拖动才触发点击弹详情；**数据对象与 DOM 元素要分开引用**（不要把 DOM 引用挂在纯数据对象上导致运行时 TypeError）；
3. **弹框内完成流程**：综合自测、知识点确认、设置，全部用弹框，不跳独立页面，减少页面间往返；
4. **延时自动触发**：节点自测由"学习达预设时长"自动生成（原型用 `setTimeout` 演示），非用户手动点按钮触发。

## 6. 页面跳转关系（可点击闭环）

```
index.html（首页）
  ├─ 导入弹框 → 架构图弹框 → learn.html
  ├─ 学习卡片 → learn.html
  └─ 更多 → 路线图列表弹框 → learn.html
learn.html（学习页，三栏）
  ├─ 完整路线图弹框 / 自测记录弹框 / 知识点确认弹框
  ├─ 头部导航 → index / knowledge / graph
  └─ 顶部头像 → 设置弹框
knowledge.html（知识库）⇄ graph.html（知识图谱）⇄ index.html
```

- 每个页面都能"进来"（有入口链接指向）且"出去"（顶部导航 / 返回链接），无孤立页、无断链。

## 7. 反 AI 味落地要点（对照铁律）

- **禁用 emoji**：全部图标用内联 SVG；
- **无紫蓝渐变、无光斑**：背景用冷灰纯色 + 径向微渐变（仅图谱画布），不做装饰光晕；
- **阴影克制**：全站统一 `0 1px 3px rgba(...,.08)` 单层轻阴影；
- **信息密度真实**：学习卡片带真实进度/统计、知识库行带真实来源路径与源码行号、图谱节点带真实知识点名；
- **配色贴合定位**：藏蓝 + 青绿（效率工具感），非默认"AI 蓝"；
- **提示文案克制**：删掉"MVP 不精确到行""后续迭代优化""点击…即可…"这类开发注脚，只保留必要状态信息（见第 8 节经验）。

## 8. 可复用经验与踩坑清单

1. **导航结构听用户的**：初版用侧边栏，用户明确否决改为顶部导航——效率工具类若用户有明确心智，应优先遵循，而非套"B2B 用侧边栏"的默认倾向；
2. **提示文案要克制**：原型页面上堆太多"功能用法 / MVP 边界 / 后续迭代"的灰字说明会显杂乱，交付前应逐页清理，只保留状态信息与必要约束（如"学习范围覆盖全部内容"）；
3. **列表页宽度**：全屏铺满会显得过宽，用 `max-width: 70%` 左右留白居中更舒适；图谱页则相反，铺满屏幕才是主视觉；
4. **弹框 vs 独立页**：流程性步骤（自测、沉淀确认）用弹框承载，比跳独立页更顺滑、更聚焦；
5. **复杂交互先验证数据引用**：SVG 拖拽/点击这类代码，数据对象与 DOM 元素分离维护，避免 `obj.domNode` 混用引发空引用异常。
