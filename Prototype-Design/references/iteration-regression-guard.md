# 原型迭代回归防护（Iteration & Regression Guard）

> 适用场景：原型进入**迭代维护**后（评审任务修复、需求变更、结构调整、数据/交互重构）。原型常把整页 JS 写在一个 `<script>` 里，任何语法错误都会让**该块全部函数与事件静默失效**——静态部分（HTML/CSS）看起来完全正常，只有动态内容空白、交互全死，极具误导性。
>
> 本文沉淀一次真实回归的完整复盘（AI 学习助手「学径」graph.html 图谱空白）与通用防护清单，供所有原型修复/重构轮次复用。

---

## 一、案例复盘：图谱分图重构后「图空白」

- **场景**：按原型评审任务清单修复「知识图谱按标签分图」。重构把图数据改为按标签的多数据集（`GRAPHS`），并把 M-11 待确认关联从「单标签」升级为「跨标签全局」——为此在数据段新增全局 `const pendingList`。
- **根因**：升级后**未删除**弹框段旧的 `const pendingList` 声明。同一作用域两个 `const` 同名 → `SyntaxError` → **整个 `<script>` 块完全不执行** → `buildGraph()` 从未运行 → SVG 空白，标签切换 / 节点点击 / M-11 全部无响应。
- **为什么难发现**：顶栏、标签卡、图例、弹框 DOM 都是纯 HTML/CSS 渲染正常，只有动态的力导向图空白——用户感知是「图坏了」，不是「页面崩了」。
- **修复**：删除重复声明（保留全局版本）。
- **连带发现**：上一轮复核截图「ok=true」只验证了截图文件生成，未人工核验内容，导致该 SyntaxError 漏检。截图成功 ≠ 内容正确。

## 二、单文件 `<script>` 的失效特征（识别信号）

| 信号 | 说明 |
|---|---|
| 页面 HTML/CSS 正常，但某块动态内容空白 | 高度怀疑该 `<script>` 整体抛错未执行 |
| 多个无关交互同时失效（点击无反应 / 数据不渲染） | 不是单个 handler 的问题，而是整块脚本没跑起来 |
| 编辑器无静态报错但运行时崩 | 单 HTML 内联脚本不经打包/转译，语法错误只在浏览器执行时报出 |

**常见触发点**：
1. 重构时**同名符号重复声明**：`const`/`let`/`function` 同名 = SyntaxError（`const pendingList` ×2）；
2. 重构时改了函数体括号/引号配平却未执行验证；
3. 字符串拼接（`'...' + x + '...'`）误伤引号或注入非法转义；
4. 代码块被挪位后引用了定义在后面的 `const`（TDZ）或定义在别的分块里的变量。

## 三、修复/迭代后的验证清单（Regression Gate）

每完成一轮多文件改动（尤其动了 `<script>` / 数据 / 弹框链），按序执行：

1. **语法校验**：抽出每个 `<script>` 内容跑一次语法检查（如 `node --check`，注意 HTML 内联脚本需先抽取）；
2. **浏览器 console 断言**（推荐，能抓 SyntaxError/TypeError）：
   - 用系统 Edge/Chrome headless 打开页面并抓取控制台：
     ```
     msedge --headless=new --disable-gpu --no-first-run --no-default-browser-check \
       --user-data-dir=<临时目录> --virtual-time-budget=3000 \
       --enable-logging=stderr --v=0 --dump-dom <URL>
     ```
   - 从 stderr 检索 `CONSOLE` 行中的 `SyntaxError` / `ReferenceError` / `Uncaught`——**必须为 0**；
3. **动态内容 DOM 断言**：对渲染产物断言关键元素数量/坐标有值，例如图谱断言 `svg#graph` 内 `<g>`/`<line>` 数量等于数据集预期、连线 `x1` 坐标已被动画更新（非全 0）；
4. **交互态截图人工核验**：关键弹框/图形/切换态**人工看图**（不是看文件大小 > N KB）。可对临时副本注入自动触发脚本（`window.addEventListener('load', …)`）再截图，不污染原型文件；
5. **资源/断链复扫**：正则扫描全站 `href/src` 本地引用是否存在（注意 JS 字符串拼接 `' + x.href + '` 会被正则误报，需人工排除）。

**PowerShell 中文路径坑**：Windows 下命令行/临时 ps1 传中文路径会乱码（目录找不到、文件名非法字符）。**一切含中文路径/文件名的操作改由 Python 脚本执行**（`write_to_file` 写 UTF-8 源文件再运行），浏览器截图输出到英文临时名、再由 Python 归档为中文名。

## 四、重构与多轮迭代的防护注意点

1. **同名符号重构 → 全文检索旧定义**：升级某能力（如单标签 → 全局）新增同名 `const`/`function` 时，必须全局搜出**所有**旧声明并删除，不能只改"使用它的地方"；
2. **整块脚本的语法错误是灾难性的**：宁可把 JS 拆成「数据段 / 逻辑段 / 初始化段」并每段可独立容错，也不要依赖"整块成功"；
3. **弹框链：开新弹框先关旧弹框**：多重弹框链（loading → 确认 → 办结）若忘记关闭高 z-index 的旧弹层，新弹框会被永久遮挡且点不穿——切换弹框前统一 `close` 当前已开的所有弹框；
4. **复核的"ok"要定义清楚**：截图工具返回的成功只代表文件产出，不证明内容正确；图形/弹框/切换类修复必须配合 DOM 断言或人工看图验收，并把截图归档为复核证据。
