## 一、定位

把一份已写好的 PRD，快速可视化成**低保真、可点击、可交互的 HTML 原型设计稿**——目标是验证 PRD 需求是否闭环、业务逻辑是否正确，为后续 UI 设计阶段提供「页面有几个、弹框有几个、何时用抽屉/表格/卡片」的布局依据。**不再是高保真 UI 设计稿。**

## 二、术语表（Glossary）

| 术语 | 英文/Key | 权威定义 | 易混淆概念排除 |
|---|---|---|---|
| 布局清单 | Layout Inventory | 本 skill 的**核心产物**：载体类型开放的载体划分清单（载体/名称/内容/宿主页面/入口/出口 + 页面间跳转关系），是生成原型布局的**主要依据**，也是后续 UI 设计阶段（UI-UX-Design）的双输入之一 | ❌ 不是页面清单（旧产物，D-03 已取消）；❌ 不含页内区块级拆解（区块结构由低保真原型 HTML 实物承载，见 UI-UX-Design D-10） |
| 载体 | Carrier | PRD「页面/功能」的落地形态，类型开放不穷举：页面/弹框/抽屉/表格/卡片/列表/表单/页内区块/Tab 等 | ❌ 不是仅指独立页面（一个 PRD 页面可能映射为弹框/抽屉等多种载体） |
| 布局清单 Gate | Layout Inventory Gate | 步骤 3 的强制关卡：AI 推荐布局清单 → 用户确认/调整后才生成原型；载体划分错了导致整个原型返工，故清单先行（D-04） | ❌ 不是生成后确认（那是被否决的一步式） |
| 低保真原型 | Low-Fidelity Prototype | 可点击、可交互的 HTML 原型：极简中性色 + 单一主色点缀 + 基础字号层级，不精修视觉 | ❌ 不是高保真 UI 设计稿（那是 UI-UX-Design 的产物）；❌ 不是纯灰白线框稿（D-02 否决） |
| 零加戏 | No Fabrication | 只画 PRD 明确要求的元素、按钮与文案；PRD 没要求的一律不画；确需补充的必须标 `【设计假设】` 并经用户确认 | ❌ 不是禁止一切补充（是补充须有据 + 标注 + 确认） |
| 闭环回写 | Write-back Loop | 用户看原型后提出调整 → 就地改原型并**同步回写《布局清单》**，保持「清单 ↔ 原型」一致 | ❌ 不是单向修改原型（清单失同步 = 返工隐患） |
| 逻辑闭环检测 | Completeness Check | 步骤 5 强制门禁：按 completeness-check.md 逐条自检 6 项（载体完整/防加戏/跳转闭环/状态覆盖/端类型匹配/假设标注），6 项全绿才放行落盘 | ❌ 不是视觉质量检测（视觉向的反 AI 味/token 统一已在 D-06 砍掉） |

## 三、决策日志

### D-01 定位变更：高保真 UI 设计稿 → 低保真原型设计稿（2026-09-04）
- **背景**：原定位「把 PRD 做成高保真 UI 设计稿」导致「确定 PRD」过程过长——高保真视觉精修与本 skill 的真实目标（验证 PRD 逻辑闭环）脱节。
- **决定**：原型设计的本质仍是「产出原型设计稿」，但保真度从高保真降到**低保真**，砍掉拖慢进度的视觉精修环节，聚焦「快速可视化 PRD → 用户确认逻辑 OK」。

### D-02 保真度定档：低保真（2026-09-04）
- 保留「基础配色 + 字号层级」（标题/正文/操作区分得清），砍掉：风格三选一、Design Token 体系、去 AI 味精修。
- 纯线框稿（灰白占位）被否决：区块一多时用户辨认效率低，拖慢「确认逻辑」。

### D-03 布局清单取代页面清单（2026-09-04）
- 原「页面清单」是偏文档记录性质的产物，取消。
- 新产物《布局清单》：载体类型**开放**（页面/弹框/抽屉/表格/卡片/列表/表单…不穷举，仅示例），是生成原型布局的**主要依据**，落盘供后续 UI 设计阶段使用。

### D-04 清单先行（两步，方案 A）（2026-09-04）
- 流程：AI 推荐《布局清单》→ 用户确认/调整 → 直接生成低保真原型。
- 「直接生成、用户对原型确认」的一步式被否决：载体划分错了低保真原型也得整体返工，先轻量对齐清单更省总时间。

### D-05 视觉基调：AI 默认，不单独风格确认（2026-09-04）
- 低保真稿用「极简中性色 + 单一主色点缀」+ 基础字号层级，由 AI 根据产品定位自动定，**不打断用户走风格确认**（风格三选一已砍）。

### D-06 检测项精简：8 项 → 6 项（2026-09-04）
- 保留（逻辑闭环向）：载体/页面完整（防漏）、防加戏（冗余元素）、跳转闭环、状态覆盖、端类型匹配、假设标注。
- 砍掉（视觉向）：反 AI 味、token 统一。

### D-07 产物结构（2026-09-04）

