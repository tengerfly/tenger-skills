# 产品方法论案例库（Case Library）索引

> 定位：写 PRD、澄清需求时**按需加载**的方法论弹药库。不是必读，是「引导用户打开思路 + 专家纠偏」的参考。
> 来源：deanpeters/Product-Manager-Skills（77 框架）、assimovt/productskills、ideaplan 36 框架、腾讯 PRD 2.0。已精编浓缩。
> ⚠️ 边界：本 skill 只做需求，框架库用于「帮用户想全、排优先级、定边界」，**不引入技术实现**；方法论框架落地仍须过 `SKILL.md` §4.1 苏格拉底拷问协议收敛。

## 一、目录

| 文件 | 内容 | 何时读 |
|---|---|---|
| `frameworks.md` | 优先级/用户研究/发现/战略/度量/商业模式/规划/需求分析 八类框架速查 | S2 澄清①、引导竞品/参考时 |
| `prd-templates.md` | 开源 PRD 模板解剖 | 写 overview/模块时参考结构 |
| `zh-cases.md` | 中文模板与案例（腾讯 PRD 2.0/阿里云/人人） | 中文语境 PRD 时 |

## 二、统一案例字段

> 场景 → 问题 → 框架/模板 → 解法要点 → 反模式 → 出处。

## 三、使用原则

1. **框架是「打开思路」的工具，不是「照单全收」**：推荐给用户选择项，错误以专家视角纠正（`SKILL.md` §4.1 第 9 条）。
2. **框架结论仍须收敛**：引用框架给出推荐后，仍按 `SKILL.md` §4.1 苏格拉底拷问过收敛证明，不因「框架这么说」跳过用户拍板。
3. **不越域界**：框架库涉及度量/灰度/技术的部分，只作参考，不写进 PRD 默认交付。
