# 前端开发专家评审检查清单

> 标准：能否照 PRD 独立完成前端页面。只关心页面/入口、功能区块、交互闭环、状态覆盖、流程断点；不关心数据库、接口、服务端逻辑、测试。

| # | 维度 | 不通畅情形 |
|---|---|---|
| FE-1 | 页面与入口完整性 | 页面无入口（无头）；职责混杂；一级入口/首屏未定义 |
| FE-2 | 功能区块清晰度 | 只有页面名无区块；关键区块缺失（如列表页无筛选/新增）；区块显隐关系不清 |
| FE-3 | 交互闭环 | 操作无反馈；反馈后无去向；反馈未定义（文案写法是否准确归产品专家 PM-5，此处只判有无） |
| FE-4 | 状态覆盖 | 空/加载/成功/失败/边界（0 条、超长、超限、无权）未定义 |
| FE-5 | 交互细节 | 触发条件、可用/禁用、校验规则未到可开发粒度；反馈粒度不足（文案写法是否准确归产品专家 PM-5） |
| FE-6 | 流程断点 | 断头/无头链路；流程死循环（通常 P0） |
| FE-7 | 越界提醒 | 出现控件名、框架/库/协议、DOM/CSS 实现细节（标越界，评审侧通常 P2；流入 PRD 后产出方按其红线 3 判 P0，修复优先级以 `prd-design` 口径为准） |
