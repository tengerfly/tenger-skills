## 二、 竞品横向功能点对比矩阵（必备）

> 在报告第 6 节输出，行 = 核心能力维度，列 = 竞品与目标产品设想。

| 功能点 / 核心能力维度 | 竞品 A | 竞品 B | 竞品 C | 竞品 D | **目标产品设想（本方案）** |
|---|:---:|:---:|:---:|:---:|:---:|
| **核心能力 1** | ✓ | ✓ | △ (基础版) | ✗ | **✓ (亮点实现)** |
| **核心能力 2** | ✗ | △ (需外接) | ✗ | ✓ | **✓ (亮点实现)** |
| **核心能力 3** | ✓ | ✗ | ✗ | ✗ | **✓ (亮点实现)** |
| **核心能力 4** | ✗ | ✗ | ✗ | ✗ | **✓ (行业绝对空白)** |

### 标注符号规范：
- `✓`：完全支持 / 体验成熟标配
- `△`：部分支持 / 体验简陋 / 需通过第三方插件或额外付费解锁（必须带简短括号说明）
- `✗`：不支持 / 无此模块
