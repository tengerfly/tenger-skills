# 数据源总集（Data Sources）

> 用途：全球检索选数据源时的速查。本 Skill 七步闭环第 4 步「全球检索」已列国内/海外主渠道，本文件补系统化工具分类。

---

| 类别 | 工具 | 用途 |
|---|---|---|
| AI 竞品情报平台 | ZeroIntel / Crayon / Klue / Kompyte | 自动追踪 + 战斗卡 + AI 报告 |
| SEO/内容情报 | SEMrush / Ahrefs / SimilarWeb / SpyFu | 关键词、流量、外链 |
| 技术栈探测 | BuiltWith / Wappalyzer / SimilarTech | 竞品用了啥技术 |
| 网站变更监控 | Visualping / Distill / ChangeTower | 页面/定价/文案变更 |
| 价格追踪 | Prisync / Price2Spy / Competera | 订阅定价变动 |
| 社媒监听 | Brandwatch / Sprout Social / Mention | 舆情、声量 |
| 招聘信号 | LinkedIn Jobs / levels.fyi | 从招人预判 roadmap |
| 评论情感 | G2 / Capterra / TrustRadius / Reddit | 真实用户痛点（金矿） |
| 市场/财务数据 | SEC EDGAR / Crunchbase / PitchBook / Statista | 规模、融资、行业报告 |
| 开源研究 MCP | RivalSearchMCP / sigint / deep-reach | 多源采集 + SWOT/五力结构化 |

## 推荐采集团栈

- RivalSearchMCP / deep-reach 做多源采集 → sigint 做 SWOT+五力结构化 → 本 Skill 模板出报告。
- 评论类走 G2/Capterra/Reddit 做痛点聚类（参考 GapHunter）。
