# 竞品分析案例库（Case Library）索引

> 定位：竞品分析时**按需加载**的框架/数据源/范本参考。本 Skill 的「数据红线 + 五层框架 + 11 模块报告」优先，本库补「扩展框架 / 数据源 / 同行范本」。

## 一、目录

| 文件 | 内容 | 何时读 |
|---|---|---|
| `frameworks-extended.md` | 补充框架速查（TOWS/定位地图/战略群组/BCG/蓝海/JTBD/赢失/战斗卡） | 现有 `references/frameworks.md` 4 框架不够用时 |
| `data-sources.md` | 数据源总集（按用途分类） | 全球检索选数据源时 |
| `agent-skill-samples.md` | 同类竞品分析 Skill 结构样本 | 优化本 Skill 结构时 |

## 二、统一案例字段

> 场景 → 问题 → 框架/工具 → 可借鉴点 → 出处 → 注意事项。

## 三、使用原则

1. **证据标准是生命线**：所有事实可溯源、禁编造、缺失标注（decision-rules §一 + SKILL 数据红线）。
2. **框架为「差异化洞察」服务**：不堆框架，选能回答「对手强哪弱哪、我差异化空间」的框架。
3. **借鉴不照搬**：同行范本的评分卡/报告模板只作参考，最终以本 Skill 五层框架 + 11 模块报告为准。
