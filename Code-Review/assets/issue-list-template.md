> - **修改说明**：用户「已忽略」时填理由；修改方「已修复」后填「改了哪个文件哪处、怎么改」；
> - 「处理建议」只给方向；P0 补丁见角色评审文档第四节，本清单不重复贴补丁（延续评审「只审不改」原则，改代码由对应 Dev skill 执行）；
