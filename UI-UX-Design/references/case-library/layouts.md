# 布局案例库（Layouts）

> 定位：案例库·布局类。两层资源：①CSS 布局原子的学习/实现资源；②按四个子类靶子沉淀真实页面布局案例（检索时按 PRD 页面类型匹配）。
> 与「布局零改动」铁律的关系：案例库供**风格决策与规范制定**阶段参考；进入生成阶段后布局以布局清单+原型为唯一真相源。

---

## 一、布局子类靶子（找案例按此归类）

| 子类 | 找什么 | 适用 |
|---|---|---|
| C 端落地页结构 | hero/特性区/社会证明/CTA 的区块编排与节奏 | 营销站、产品官网 |
| 中后台信息架构 | 列表+筛选、详情、表单、仪表盘、设置页的区块组织 | B 端工具、SaaS 主面板 |
| 导航模式 | 顶栏/侧栏/Tab 底栏、折叠与响应式行为 | 全部 |
| 响应式栅格 | 断点策略、栏位折叠、限宽/全宽分层 | 全部（对齐设计门禁 §六） |

## 二、布局学习与实现资源

| 名称 | 链接 | 许可 | 案例库价值 |
|---|---|---|---|
| Every Layout | https://every-layout.dev | 书（部分免费） | Heydon Pickering 的「自管理、无媒体查询」布局原子：Stack/Sidebar/Cluster 等，现代 CSS 布局思想源泉 |
| web.dev · Learn CSS Layout | https://web.dev/learn/css/layout/ | 免费 | Flexbox / Grid / 定位 系统讲解，带官方示例 |
| Grid by Example（Rachel Andrew） | https://gridbyexample.com | 免费 | CSS Grid 模式与示例库，快速起手网格布局 |
| CSS Layout Visual Playground | https://drjulsgilliam.github.io/HTML-CSS-Visual-Playground/layout-lesson.html | 免费 | 可视化分步讲解 normal flow → flex → grid → position → 整页布局 |
| MDN Web Components Examples | https://github.com/mdn/web-components-examples | CC0 | 官方 Web Components 模式实现 |

**沉淀格式**：按「一维(Flex) vs 二维(Grid) vs 定位(Position)」归类，每条配一个最小可运行代码片段 + 适用场景。
