# 灵感与用户流案例库（Flows & Inspiration）

> 定位：案例库·流程与状态类——「案例库最该重仓的部分」。真实产品的完整用户流与界面状态表达；按「场景 → 问题 → 解法 → 可借鉴点」四栏记录。
> 与界面状态规范的关系：design-system §5.10 定义「该有什么状态」，本库提供「优秀状态设计长什么样」的真实参考（Mobbin/UX Archive 均可按 empty state / error state 筛选）。

## 二、重点场景子类（与 10 大 UI 状态呼应）

| 场景 | 检索入口 | 看什么 |
|---|---|---|
| 空态表达 | Mobbin「Empty State」/ UX Archive | 插画风格、文案语气、CTA 位置 |
| 错误/失败态 | Mobbin「Error State」 | 错误 Banner 结构、重试出口、语气 |
| 首次加载 | Mobbin「Onboarding / Loading」 | 骨架屏结构一致性、进度表达 |
| 注册/引导流 | Pageflows / Really Good UX | 步骤拆分、进度指示、跳过策略 |
| 设置/偏好流 | UX Archive「Settings」 | 分组方式、开关密度、层级 |
