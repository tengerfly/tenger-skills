## 案例：学径 LearnPath · AI 学习助手（2026-09-05 定稿）

- **产品类型 / 定位**：个人 AI 学习工具——资料导入→AI 生成学习路线图→节点学习（对话+划线笔记+自测）→沉淀知识库→知识图谱。5 主态页 + 弹框专稿。
- **风格方案**：方案 A「专注效率」——藏蓝 `#1E3A5F` × 青绿 `#2C7A7B`、页面冷灰 `#F7F9FB`、正文 14–15、圆角 4/6/10、密度适中；product 语境。
- **基线体系**：Ant Design 5（Seed→Alias 分层思路）+ 自建语义浅底对；导航激活=青绿浅底方块。
- **布局模式**：顶栏 58px 三段式（brand 左 `mr-auto` / 导航组 + 头像靠右 / 头像最右）；限宽页（首页/知识库/学习计划）顶栏内容列 = 内容主列同宽 `page-col`（1280→1200，≥1536→1440 响应放大，居中）；全宽页（学习三栏/图谱）内容铺满。
- **组件要点**：nav item 宽度按内容自适应（`min-w` + nowrap，禁固定 38px 装 4 字标签）；弹框宽度 7 档 560~880；状态 8 色 badge 用浅底深字对；头像拟真昵称下拉（学径探索者/Pro 账户，头像字「学」）全站统一。
- **踩坑清单（每条=为何错+正确做法）**：
  1. **布局决策未拍板就生成** → 顶栏是「全宽铺满」还是「与内容同宽居中」两版反复改 → 步骤 4 先把「每页宽度分层 + 顶栏列宽 + 内容与顶栏关系」问清写规范，再做；
  2. **修改范围蔓延** → 用户只要改内容区宽度，却连已定稿顶栏也逐页改宽 → 全局组件一旦定稿为跨页不变量，改动只针对被指认对象，改全局要先回基线再全站适配；
  3. **上下宽度不一致** → 顶栏 1200 而内容主列 960/70% 窄列 → 限宽页顶栏与内容必须同一容器列（§B），内容内部不再二次窄列；
  4. **限宽值死锁** → 把「当前屏 1200」写死 `max-w-[1200px]` → 用响应式列 `width:100%;max-width:N;margin:auto` + 大屏断点放大；
  5. **文案正确≠完整显示** → nav 4 字 11px 在 38px 方块换行、视觉稿未发现 → 中文 N 字×字号≤容器宽检查（设计门禁 §六C / 评审 §七）；
  6. **单视口验证盲区** → 只在 1280 截图 → 大屏缺陷（不铺满/不放大）全漏 → 至少补 1 张 ≥1440/1920 宽屏快照；agent-browser 1920 不稳时用 Edge headless + 独立 user-data-dir；
  7. **下拉 hover 断点** → 头像下拉菜单定位用 `top-full mt-2`，头像与菜单间 8px 空隙使指针移向菜单即隐藏、设置点不到 → 悬浮层必须「触发器↔浮层 hover 通路连续」：用 `top-full + padding-top` 透明桥接或紧贴消除空隙（同族：带 gap 的 dropdown/tooltip 一律此类）；
  8. **浮层越界被裁/层级不足** → 图谱右上 icon 的 tooltip 原向上弹出，越出内容区上边界撞 sticky 顶栏被裁 → tooltip 弹出方向须避开 `overflow:hidden` 容器边界与 sticky/高 z 兄弟层，必要时向下弹出 + 提高 z-index（`z-[70]`）并对图例/关联等 icon 触发器补描述性 id 便于 hover 定位与还原评审；
  9. **弹框/入口缺失闭环（P0）** → 头像菜单「设置」在 4 个主态页被做成无动作 button，点击无弹框（只有 index 指向设置专稿），设计与评审均漏 → 弹框若独立成稿，**一切触发入口（含下拉/菜单项）必须用可达链接指向其专稿**；评审/还原把「下拉与菜单内入口」也纳入逐入口点击，入口无去向=至少 P1、主流程弹框缺失=P0。
- **稿源**：Superdesign projectId `7afdaa26-cff0-4f63-9e4d-8df931e10218`；项目级复盘 `.spec/设计评审/沉淀_评审盲区复盘_导航换行与大屏铺开.md`。
