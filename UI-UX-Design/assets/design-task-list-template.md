## 三、基线复刻（Replica）规则

> 基线复刻是步骤 6 `create-project --template` 的输入：表达**结构**，不表达**风格**。

- 按布局清单（载体划分）+ 低保真原型（区块实物）逐区块摆出真实结构（分栏 / 堆叠 / 栅格 / 导航位），弹框抽屉以隐藏区块或注释标注宿主挂载点；
- 灰基调（#f5f5f5 底 / #333 文字 / 无品牌色 / 无阴影渐变装饰），占位内容用布局清单的真实文案与要素数量（统计卡 4 张就是 4 张）；
- 文件命名与布局清单页面文件名一致（`list.html` → `list.html`），存 `.superdesign/replica_html_template/`；
- 与 Wireframe 的关系：若 Prototype-Design 已产出 wireframe，基线复刻可直接在其结构上灰调化，不重摆。

## 四、确认规则

- 任务清单呈现给用户过目（页面数、每页视觉要点）——用户确认后进入风格决策 Gate；
- 后续每页状态随流程更新；返工页在「视觉要点」列追加返工原因，供案例库沉淀。
