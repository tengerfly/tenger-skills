# 载体与结构零改动检查清单

> 对照物：**布局清单（载体级，权威） + 低保真原型 HTML（区块级实物）**；设计任务清单仅作行号索引，不作独立基准（它是被审方派生件）。忠实穿衣，禁增删移结构；独立复核，不采信生成方门禁。

| 类别 | 检查项 |
|---|---|
| 页面覆盖 | 独立页面一一对应、无少/多/改名；文件名一致；端类型匹配 |
| 区块结构 | 区块数量/类型/位置一致；组件类型一致；列定义、表单字段、弹框宿主、内容要素数量一致 |
| 跳转 | 可跳转入口 href 与站点地图一致；无空 href/# 死链、无孤儿目标；〔A〕禁相对路径，〔B〕同目录相对链接合法（判据 `ui-ux-design/references/self-write-review-gate.md` §2） |
| 防加戏 | 每个按钮/操作有 PRD 出处；无多余区块/卡片/推荐位/装饰 |

分级：核心载体缺失/多出 P0；局部偏差 P1；纯装饰 P2。
