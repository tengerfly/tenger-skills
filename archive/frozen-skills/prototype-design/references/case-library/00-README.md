# 原型设计案例库（Case Library）索引

> 定位：生成原型时**按需加载**的方法论与范本参考。⚠️ 本 Skill 定位「低保真可点击 HTML 原型」（验证逻辑，不精修视觉），案例库只补方法论/反模式/可用性测试/范本，不改变低保真定位。

## 一、目录

| 文件 | 内容 | 何时读 |
|---|---|---|
| `prototyping-methods.md` | 保真度分级/反模式/可用性测试/AI 角色边界/生命周期状态 | 布局清单 Gate、闭环检测时 |
| `prototyping-tools.md` | 线框/高保真/白板/中文工具速查 | 选工具时（本 skill 直接产 HTML，工具仅参考） |
| `agent-skill-samples.md` | 同类「动作生成型」原型 Skill 范本 | 优化本 Skill 结构时 |

## 二、统一案例字段

> 场景 → 问题 → 解法 → 出处 → 适用边界。

## 三、使用原则

1. **低保真定位不变**：资料里的「高保真分级/高保真工具」只作参考，本 Skill 仍产出极简中性色 HTML。
2. **零加戏铁律优先**：范本里的设计语言规范/组件库只借鉴「方法论」，不照搬视觉复杂度。
3. **范本的动作型范式可反哺**：生命周期状态（换数据不换外壳）、URL 状态分享、反馈闭环——可作为现有「闭环检测 + 回写清单」的增强参考，不推翻现有流程。
