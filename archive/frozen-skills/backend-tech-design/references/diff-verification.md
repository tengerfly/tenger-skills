# 求差类核对三要件（防自造量具假信号）

> 适用：任何「零承接 / 缺 N 条 / 存在非法边 / 覆盖不足」这类**求差结论**。机械核对用于替代目测，其输出可直接写入交付物；但量具必须先证明可信（本仓 2026-09-23 曾三次给出假信号，两次由自造量具造成：未展开斜杠导致假缺、脚本对全文跑正则把否定句当状态边导致假红）。

## 三要件（缺一不得写入交付物）

1. **命令原文**：出具结论必须附本次实际运行的求差命令（grep/perl/python 脚本全文，含正则与展开逻辑）。
2. **基线集合取法**：说明基线从哪些文件取、是否展开区间（`A~C`）与斜杠（`AC-M03-001/002/003`）、是否覆盖 CHANGELOG 等旁路文件。
3. **反向对照**：故意注入一个已知违规样本（一条非法状态边、一个缺失的 AC 编号），证明检查器会报红（exit≠0 或命中数增加）；未做反向对照的「全绿」不得采信。

## 铁律

- **结构块外正文不参与解析**：状态机 / 枚举 / 编号解析只限 `stateDiagram` 块内或明确编号区段；正文里的「不存在 X / 不得画 X」这类自然语言否定句不得进入解析域（否则假红）。
- **覆盖矩阵逐条编号**：AC↔用例登记禁用区间/斜杠折叠（`A~C`、`M03-001/002/003`），一律展开成单条编号——折叠写法同时是假绿与假红来源。
- **先证会红、再信会绿**：S7 全局一致性核对按此顺序执行（见 SKILL.md S7）。
