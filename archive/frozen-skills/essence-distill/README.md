# Essence-Distill（精华蒸馏）

给定一本书、一个 GitHub 仓库或一份学习资料，产出**高密度、条条可溯源的精华文档**：不是全文摘要，不是书摘金句集，是把「懂了它就懂了它 / 能直接拿来用」的精华压成一份文档（目标压缩比可达 100:1），每条带原文锚点、交付前回源抽验。

## 快速开始

```
把《纳瓦尔宝典》蒸馏成精华笔记
蒸馏一下 langgenius/dify 这个仓库的精华（思想/设计决策/最佳实践）
这篇长文太长了，帮我提炼干货（速览档）
把这门课的讲义蒸馏成行动清单（行动档）
```

## 产出

落盘 `<工作区>/.spec/精华蒸馏/<来源slug>/`：

- `精华.md` —— 主交付：一页总览 + 分类精华（核心主张/方法论/案例/金句/反常识/行动项，每条 = 主张 + 展开 ≤4 句 + 原文锚点 + 适用边界）+ 附录三件套（推断区 / 丢弃台账 / 核验记录）+ 压缩比
- `00-总览.md` + `NN-<主题>.md` —— 大源拆分形态

## 三档位（按目的选）

⚡ 速览档（判断值不值得读）· 📚 学习档（默认，真正掌握）· 🛠 行动档（每条带怎么用）

## 四条命根子

通俗（说人话）· 不啰嗦（单条 ≤4 句、全文有红线）· 逻辑清晰（精华地图 + 编号即阅读顺序）· 前置铺垫（链接宁缺毋错）

## 铁律（精选）

无文本不蒸馏 · 锚点必真实（位置+内容双匹配）· 推断与原文严格区隔 · 丢弃留痕不静默 · 冲突原文并存 · 只读不改源材料

## 边界

- 不是 ML 训练数据蒸馏，不产读后感/书摘/全文摘要
- 仓库逐行走读学实现 → `Source-Reading`
- 产品/竞品调研 → `Competitive-Analysis`；AI 结论辨伪 → `Fact-Check`；开源实践反哺 skill → `OSS-Radar`
