# 后端进阶导读 · 任务计划（7 仓逐一交付）

> 目标读者：只会写后端接口的开发者（TS/NestJS 背景），通过读真实项目源码完成后端进阶。
> 进阶维度（用户点名）：架构思想、数据库表设计思想与选型、消息队列、权限设计、其他后端进阶思想与流程。
> 风格硬要求（记忆）：通俗不啰嗦、逻辑动线清晰、前置先铺垫、链接宁缺毋错。
> 执行法：Source-Reading 三段式（结构摸底 → 大纲先行 → 按纲填充 → 成文复核）→ Fact-Check 核验 → 补遗（≤3 轮）→ 下一仓。
> 产物**不主动 commit**，全部完成后由用户决定。

## 每仓统一闭环

1. 核实仓库地址（GitHub REST API）→ 浅克隆到 `.spec/源码学习/_clones/<repo>`（记 commit）
2. 侦察结构 → 深读（业务项目命题清单见下）→ 大纲先行 → 按纲成文 → 成文复核
3. Fact-Check（`Skill(Fact-Check)`）：拆文档承重断言 → L3 源码为主 + L2 官方文档 + 反证 → 四值判定落 `fact-check.md`
4. 补遗：❌必改、❓标注下一步、维度遗漏必补；**轮次 ≤3，超限记录遗留项停手进下一仓**；复核只验本轮修改点
5. skill 出问题 → 记入本文件问题日志 → 按 Skill-Optimizer 优化源仓 skill → `cp` 同步 .codebuddy 安装副本

- 复核只验本轮修改点，不整体重跑
