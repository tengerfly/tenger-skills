## 逐章功能点清单

### 章1 最佳实践清单
- bootstrap：全局 ValidationPipe + TransformInterceptor + CORS（main.ts:10-14）
- ConfigModule 多环境文件 `.env.stage.${STAGE}` + Joi 校验（app.module.ts:10-13；config.schema.ts:3-12）
- TypeOrmModule.forRootAsync 工厂注入 ConfigService；ssl 按环境；autoLoadEntities；synchronize:true（app.module.ts:15-36，⚠️ 生产慎用要标注）
- TransformInterceptor：classToPlain 响应序列化（transform.interceptor.ts:11-14）

### 章2 认证主线
- signUp：repository.createUser，bcrypt genSalt+hash（users.repository.ts:15-16）；唯一冲突 23505→ConflictException（:23-25）
- signIn：bcrypt.compare + jwtService.sign({username})（auth.service.ts:27-30）
- 受保护请求链：@UseGuards(AuthGuard())（tasks.controller.ts:23）→ passport-jwt 策略 validate 回库找用户（jwt.strategy.ts:23-32）→ @GetUser() 自定义参数装饰器取 req.user（get-user.decorator.ts:4-9）

### 章3 数据层与任务主线
- 自定义 Repository 继承 typeORM Repository（tasks.repository.ts:9-10）
- getTasks 动态条件 QueryBuilder + 参数化 LIKE（:16-28）；异常日志+InternalServerError（:33-40）
- 按用户隔离：所有任务查询 where({user})（tasks.service.ts:21-22；repository :17）——「数据权限」最简形态
- DTO 校验 @IsNotEmpty（create-task.dto.ts:3-8）
- 单测样例：mock repository 工厂 + Test.createTestingModule（tasks.service.spec.ts:7-27,35-38）

### 章4 收束
- ⚠️ 坑位清单：NestJS 7.x 老版本（2021）、synchronize:true、user.tasks eager + password 无 @Exclude 的隐患（以代码为准的审查示范）
- 与 RuoYi/mall/GVA 对照一句话
- 引出通关秘籍（进阶特性全景）与 Nestier（架构思想）
