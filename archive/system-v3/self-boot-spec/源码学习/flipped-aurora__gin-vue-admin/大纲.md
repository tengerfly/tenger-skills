## 逐章功能点清单

### 章1 架构与请求动线
- main.go:30 → core 启动 → initialize 系列（router.go:66-68 PrivateGroup 挂 JWTAuth()+CasbinHandler()；:82-87 分模块注册路由）
- Go 目录职责表：api(控制器)/service(业务)/model(实体)/middleware(中间件)/global(全局单例)/initialize(装配)/source(种子)/plugin(插件)/task(定时)
- NestJS 对照表：Gin handler≈Controller、middleware≈Guard/Interceptor、global≈简化版 DI、initialize≈AppModule 装配
- 统一返回 Result{code,data,msg}（model/common/response/response.go:10-12）

### 章2 认证
- x-token 头 + JWT 解析（middleware/jwt.go:18-33）
- 黑名单拦截：本地 BlackCache（:25-30,86-89）+ Redis 服务（service/system/jwt_black_list.go）
- 缓冲期续期：剩余<buffer-time 发新 token 进 new-token 响应头（:56-68；config.yaml:4-8 expires 7d/buffer 1d）
- 多点登录：UseMultipoint + SetRedisJWT（:64-67）
- 三家会话方案对比（RuoYi Redis 双层 / mall 纯无状态 / GVA 无状态+黑名单）

### 章3 鉴权
- Casbin 前置铺垫（sub/obj/act 三元组策略引擎）
- 中间件：Enforce(AuthorityId, path, method)（middleware/casbin_rbac.go:13-31）
- enforcer 构建：SyncedCachedEnforcer + gormadapter（策略存 DB casbin_rule 表）+ 内嵌模型串（utils/casbin_util.go:20-43）
- 策略管理界面化：UpdateCasbin/GetPolicyPathByAuthorityId（service/system/sys_casbin.go:26,110；改 API 同步 :88）
- 用户多角色：sys_user_authority 连接表 + 登录选定 AuthorityId 进 claims（sys_user.go:29; sys_user_authority.go:4-7; SetUserAuthority sys_user.go:140+）
- 路由注册按 Public/Private 分组（initialize/router.go:66-87）

### 章4 表设计与工程化
- GORM 模型即表：tag 里 index/comment/foreignKey/many2many（sys_user.go:22-32）
- 自动迁移 AutoMigrate（initialize/gorm_biz.go:9）+ ensure_tables —— vs RuoYi/mall 的 SQL 脚本
- 代码化种子：source/system/*.go + RegisterInit + initOrder 顺序编排（authority.go:12,18）
- 多数据库适配：gorm_mysql/pgsql/oracle/mssql/sqlite（initialize/ 五件）
- GORM 函数式事务（sys_api.go:137 等）
- 操作日志中间件读 body 入库（middleware/operation.go:31-79）
- 定时任务 robfig/cron（initialize/timer.go:14-17 ClearDB @daily）

### 章5 代码生成器与插件
- auto_code 系列：package/history/llm（service/system/auto_code_*.go 清单）——生成器可建「包」、有历史、接了 AI
- 插件系统：plugin/{announcement,email,auto,plugin-tool} + register.go 注册；initialize/plugin*.go 装配

### 章6 收束
- 四项目对照总表（会话/鉴权/迁移/种子/生成器/MQ）
- 标准件思维：Casbin（权限界的 Express）vs RuoYi 自研 vs mall 动态 URL
- Go vs TS 栈对照收尾
- 引出 NestJS 三仓
