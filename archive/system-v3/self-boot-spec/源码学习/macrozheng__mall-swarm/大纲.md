## 逐章功能点清单

### 章1 服务拆分对照
- 9 模块清单（pom.xml:13-21）；新增 mall-gateway/mall-auth/mall-monitor
- 与 mall 逐服务对照（admin/portal/search 业务不动，底座 common/mbg 不变）
- config/ 目录 = Nacos 配置样例（admin/demo/gateway/portal/search 五组 dev/prod）

### 章2 网关
- 路由：discovery locator + 显式 routes `lb://mall-auth` + StripPrefix=1（mall-gateway application.yml:15-40）
- SaReactorFilter 全拦截+白名单 exclude（SaTokenConfig.java:40-45）
- 双账号路由匹配：/mall-portal/**→StpMemberUtil.checkLogin、/mall-admin/**→StpUtil.checkLogin（:50-53）
- 权限判定：Redis hash PATH_RESOURCE_MAP + AntPathMatcher + checkPermissionOr（:56-73）

### 章3 认证中心与服务间调用
- auth 是 Feign 薄聚合：@FeignClient("mall-admin") POST /admin/login（auth UmsAdminService.java:16-20）；clientId 区分 admin/member（AuthController.java:34-46）
- 真实登录在业务服务：StpUtil.login(admin.getId())（mall-admin UmsAdminServiceImpl.java:89-104）返回 SaTokenInfo
- 双账号体系：StpMemberUtil TYPE="memberLogin" + StpLogicJwtForSimple（StpMemberUtil.java:44-49）
- demo 的三个 Feign clients 示例（FeignAdminService 等 :11-13）

### 章4 老问题新答案
- 权限规则集中制：admin 服务资源变更时重建 Redis hash（UmsResourceServiceImpl.java:85-86），网关只读（AuthConstant.java:37）
- MQ 原样保留：CancelOrderSender/Receiver + RabbitMqConfig + 10min 兜底 cron（portal component 三件，:24）
- 监控：spring-boot-admin-starter-server + security（mall-monitor pom.xml:28,32）
- 已核实不存在：Sentinel（全仓 grep 无，仅仓库简介提及）、Seata（无，README:93 技术栈表提及）——宣传与代码不符，以代码为准
- Nacos：注册发现 + 配置中心（各服务 pom + config/ 样例）

### 章5 收束
- 拆分收益：独立部署/独立扩容/团队分工/故障隔离
- 拆分代价：网络调用（Feign）、运维复杂度（Nacos×2 用途+网关+监控）、配置爆炸（config/ 五组文件）、认证被逼成中心化
- 判断准则：什么时候才值得拆
- 引出 gin-vue-admin（换语言看同一批问题）
