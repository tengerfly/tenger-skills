# 精华文档模板（步骤③④ 加载）

按档位选用。`{{ }}` 为占位。六类标签：`核心主张` / `方法论·框架` / `案例与证据` / `金句` / `反常识·警告` / `行动项`。

```markdown

| # | 类型 | 精华（一句话主张） | 出处 |
|---|---|---|---|
| 1 | {{标签}} | {{主张}} | {{锚点}} |
| … | | | |

## 深读建议
- {{值得精读的部分：哪几章/哪几个文件/哪几节，为什么}}
- {{不值得花时间的部分}}
- {{这份材料没回答的问题（1~3 条）}}
```

## 大源拆分形态

`00-总览.md`（元信息 + 一页总览 + 各部索引）+ `01-<主题>.md`…（每部 = 该主题的精华 + 本部附录三件套，单部 ≤400 行）。

## 写卡规则（③④ 共用）

1. 主张必须是**完整陈述句**，删掉后卡片不可读 = 主张没写好。
2. 展开只做三件事之一：解释主张 / 给原文证据 / 给适用反例——不做第四件事（抒情、复述、凑字）。
3. 锚点宁细勿粗：指到章/块/行，不指到全书/全仓库。
4. 金句类必须带「为什么值得记」（一句话），否则只是摘抄。
5. 行动项必须可直接执行（动词开头、有对象、有判据），做不到 = 降级为方法论。
