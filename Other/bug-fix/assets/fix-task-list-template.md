## 3. 操作指引（闭环规范）

1. **方案方（Backend/Frontend-Tech-Design）**：读取 `问题定位报告.md` 与 `修复任务清单.md`，按受影响模块出增量 TDD/FTDD，产物落各自方案目录，回填状态 `方案已确认` + 产物路径。
2. **开发方（Backend/Frontend-Dev）**：按方案与判据精准修复，先落回归测试再实现；改完自测；回填 `已修复` + 改动说明（哪个文件、哪处、怎么改）。
3. **回归（委托 + Bug-Fix 收尾）**：回归动作由开发自测（+ 按需 Testing）执行并回填结果；Bug-Fix 收尾只核对「原始场景不再现」并判定状态为 `已验证` + 验证说明。回归不过 → 按迭代判定退回对应环节（根因退定位、方案退方案、实现退开发），附原因，同批复核只验本轮。
