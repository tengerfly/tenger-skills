# Essence-Distill（精华蒸馏）

> IRON LAW：产出必须**压缩保真**——每条精华都能顺着锚点回到原文（位置+内容双匹配）；原文没说的不冒充原文说的（推断单独区并标注）；被丢掉的不静默消失（丢弃台账）。
> 定位：精华提取器。不是全文摘要（按结构平均用力复述），不是书摘金句集（有句无观点），是把材料里「懂了它就懂了它 / 能直接拿来用」的精华，压成一份密度最高、条条可溯源的文档。
> 术语约定：「材料」泛指一切被蒸馏对象——书籍、GitHub 仓库、长文、课程讲义、视频/播客转写、资料集。

## 一、四条命根子（所有产出逐关自检）

1. **通俗易懂**：每条精华用大白话讲——主张一句话能复述给没读过的人；术语首次出现必须一句话解释。禁止堆术语、禁止官话。
2. **不啰嗦**：单条精华展开 ≤4 句；速览档全文 ≤60 行；完整档正文 ≤400 行（超了拆分部）。蒸馏品比原材料还啰嗦 = 重写。
3. **逻辑清晰**：精华按主题/重要性分组排序，编号即推荐阅读顺序；总览给「精华地图」，读者不迷路。
4. **前置铺垫 + 链接宁缺毋错**：讲解用到用户可能不懂的前置概念先给 2~3 句简介；外部链接必须核实过才给，拿不给改给精确搜索关键词——错误链接比没有链接害人。

## 二、流程（七步：⓪输入确认定档 → ①取源摸底 → ②通读定位 → ③蒸馏成卡 → ④结构化成文 → ⑤回源核验 → ⑥交付）

### ⓪ 输入确认与定档

1. 输入四类：**书**（PDF/EPUB/TXT/多文档）、**GitHub 仓库**、**单篇资料**（文章/讲义/转写/网页）、**资料集**（多文件/多来源）。
2. **无文本不蒸馏**：文本拿不到（扫描版 PDF 无 OCR、视频/播客无转写、闭源仓库只看过介绍）→ **停下来要文本**，绝不「凭我对这本书的了解」直接蒸馏——记忆≠原文，锚点必漂、脑补必混。
3. 元信息确认：书 = 书名+作者+出版年；仓库 = `owner/repo`；资料 = 标题+作者+链接/日期。用于目录命名与出处标注。
4. **目的定档**（一次问清：目的+深度；用户未响应 → 按默认档执行，在交付头部留档声明「未响应，按学习档自动执行，可事后补改」——不许因等待阻塞交付）：

| 档位 | 适用目的 | 形态 |
|---|---|---|
| ⚡ 速览档 | 快速判断值不值得深读 | 一页纸：定位 3 句 + 5~8 条精华 + 深读建议 |
| 📚 学习档（默认） | 真正掌握这份材料 | 完整精华文档：总览 + 分类精华 + 附录三件套 |
| 🛠 行动档 | 拿来指导做事 | 方法论/清单/流程为主，每条必带「怎么用」 |

### ① 取源与结构摸底（**此步加载** `references/extract-playbook.md`）

按输入类型取文本（playbook：PDF/EPUB 抽取、网页存档、转写获取、仓库浅克隆与瘦身——克隆策略复用 `../Source-Reading/references/clone-playbook.md`）。摸清结构：书 = 目录章节，仓库 = 文件树 + README + docs，资料 = 小节标题。规模分档：小 = 单文件直读；中 = 分块精读；大 = 高密度区预算集中。产出**结构地图 + 文本可得性结论**（哪来的文本、什么格式、怎么定位）。

### ② 通读与精华定位

1. **两遍法**：第一遍结构通读（这份材料在解决什么问题、骨架是什么、作者/项目的核心立场）；第二遍定位**精华高密度区**——核心章/核心文件/核心论点所在，把阅读预算集中投在那里，长尾章节快扫。平均用力 = 高级搬运。
2. 同步建**关键问题清单**（读者读它最想得到答案的 5~10 个问题）——这是③覆盖率自查的基准。
3. 产出**候选精华池**：每条候选随手记类型标签（六类：核心主张 / 方法论·框架 / 案例与证据 / 金句 / 反常识·警告 / 行动项）+ **锚点**。锚点体系：书 = `第N章·页码`；无页码文本/转写 = B 块号（①步按自然段落建 B1/B2… 块索引）；仓库 = `文件路径:行号`；网页 = 小节标题+URL；资料集 = `文件名#小节`。

### ③ 蒸馏成卡（REQUIRED）

每条候选过三道筛：

- **V1 可溯源**：能定位原文，且原文足以支撑这条主张——锚不出来的直接丢，记丢弃台账。
- **V2 有含金量**：懂了它就懂了这份材料，或能直接指导行动/决策——金句无观点、正确废话、作者复读常识的不收。
- **V3 属于原文**：是作者/项目说的，不是我以为的——我的引申、联想、补充 → 一律进推断区。

通过的成卡，格式固定：**主张（一句话）→ 展开（≤4 句）→ 锚点 → 适用边界/条件 → 行动启示（行动档必填，其他档可选）**。

**覆盖率自查（REQUIRED）**：②步关键问题清单逐条过——有对应精华 → 标注指到哪条；没有 → 写结论行「该材料未回答此问题」。不虚报零遗漏，也不硬凑答案。

### ④ 结构化成文（**此步加载** `assets/essence-template.md`）

- 速览档：一页纸（定位 3 句 + 精华表 + 深读建议）。
- 学习/行动档：头部元信息（来源/档位/日期/压缩比声明）→ 一页总览（它讲什么、为什么值得读、精华地图）→ 分类精华（六类分组，组内按重要性排序）→ **附录三件套**：A 推断与引申区（显式标注，与原文区隔）/ B 丢弃台账（候选 + 丢弃原因一行）/ C 核验记录（⑤抽验结果）。
- 大源（完整档正文将超 400 行）：按主题拆 `NN-<主题>.md` + `00-总览.md` 做索引。
- **冲突并存**：作者前后矛盾、多来源冲突时，各自保留原话与适用条件，不抹平成一条四平八稳的假共识。
- 写作中发现新精华：先补进候选池过③的三道筛，再入正文——不许绕过验证直接写。

### ⑤ 回源核验（REQUIRED，交付前）

1. **锚点抽验 ≥3 条**（抽此前未核过的）：打开原文做「位置+内容」双匹配——该处存在且内容与卡片主张一致才算核过；对不上必修，修不动 → 降级为推断或丢弃。
2. **脑补自检**：逐条问「原文确实这么说？」——AI 最常见的病是拿自己的知识替作者把话说满。
3. **区隔自检**：推断区/原文区没有串味；丢弃台账里的东西没有混进正文（反之亦然）。

### ⑥ 交付

1. 落盘 `<工作区>/.spec/精华蒸馏/<来源slug>/`（书 = 书名短横线，仓库 = `owner__repo`，对齐 Source-Reading 命名）。
2. 给用户：精华地图（总览段）+ 建议从哪条读起 + **「哪些问题这份材料没回答」**（覆盖率结论）。
3. 仓库来源若用户实际想逐行学实现 → 建议转 `Source-Reading`（本 skill 提炼思想/决策/最佳实践，不替代源码走读）。

## 三、产物落盘

| 文件 | 内容 |
|---|---|
| `精华.md` | 主交付：速览=一页纸；学习/行动=总览 + 分类精华 + 附录三件套 + 压缩比 |
| `00-总览.md` + `NN-<主题>.md` | 大源拆分形态（编号 = 阅读顺序） |
| （可选）`原文索引.md` | 资料集/仓库：精华点 ↔ 原文位置对照表 |

压缩比写进交付头部（例：30 万字 → 320 行精华 ≈ 100:1）。

## 四、铁律

1. **无文本不蒸馏**：宁停下要文本/转写，不凭记忆蒸馏。
2. **锚点真实**：所有出处出自本次实际读取的文本；交付前抽验「位置+内容」双匹配。
3. **区隔推断**：原文没说的进推断区并显式标注，永不混入精华正文。
4. **丢弃留痕**：不收录的候选进丢弃台账（原因一行），不静默消失。
5. **冲突并存**：矛盾原文各自保留条件，不抹平成假共识。
6. **密度优先**：宁缺毋滥；压缩比与行数上限写进交付，超限重写。
7. **目的对档位**：未确认按学习档执行 + 头部留档声明，不阻塞。
8. **只读不改**：对源材料零改动。
9. **链接宁缺毋错**。
10. **只产精华文档**：不产读后感、书摘、全文摘要，不产可执行 Agent Skill（外部已有 cangjie-skill 类工具，见 CONTEXT.md 调研）。

## 五、常见错误对照表

| 错误 | 纠正 |
|---|---|
| 按目录逐章复述，平均用力 = 高级搬运不是蒸馏 | 两遍法定位高密度区，长尾快扫，预算集中 |
| 「凭我对这本书的了解」直接开写 | 铁律 1：无文本不蒸馏，先要文本 |
| 精华条没有出处，没法回查 | 每条带锚点；⑤ 抽验「位置+内容」双匹配 |
| 用 AI 自己的知识脑补作者观点 | ③-V3「属于原文」筛；引申一律进推断区 |
| 丢掉的候选静默消失，读者以为是全文精华 | 丢弃台账显式记录 + 原因 |
| 金句堆砌，有句无观点 | V2 含金量筛：无主张/无行动价值的不收 |
| 全是观点没有案例、数据支撑 | 六类标签保留「案例与证据」类，主张配证据 |
| 30 万字的书想一口气读完再蒸馏 | 分块 + 高密度区预算集中（extract-playbook） |
| 扫描版 PDF 打不开，硬着头皮编 | 停下要文本/OCR，交付文本可得性结论 |
| 仓库蒸馏写成 API 手册/源码走读 | 那是 Source-Reading；这里提炼思想/决策/最佳实践 |
| 冲突说法被抹成一条谁也不得罪的「共识」 | 各自保留原话与条件，冲突并存 |
| 写完全文不核验直接交付 | ⑤ REQUIRED：抽验 + 脑补自检 + 区隔自检 |
| 输出比原文还啰嗦，或速览档写成一本书 | 行数红线 + 压缩比报告，超限重写 |
