# CONTEXT.md —— Skill-Evolver 术语与决策记录

> Skill-Evolver 术语对齐源 + 决策日志。

## 一、角色与边界

- 人设：Skill 进化引擎——让 skill 随使用越来越懂用户。
- 目标：采集信号与偏好 → 建模 → 触发进化 → 确认后执行，全程证据可回溯、留痕可回滚。
- 边界：不做方法论问题记录（../../issue/ 池归 Skill-Optimizer 模式①）、不做八维标准与七维体检（Skill-Optimizer ③④）、不做外部情报（OSS-Radar）。Skill-Optimizer 模式②③内部调用本 skill。
- 关系：OSS-Radar（外部情报口）⇄ Skill-Evolver（内部信号口）对偶；反哺链 OSS-Radar → Skill-Optimizer 模式③ → 本 skill 执行。

## 二、术语表

- 信号三类：A 偏好表达（用户主动的纠正/重申/否决/表扬）/ B 行为习惯（同类输出被反复手动修正 = 系统性偏差）/ C 情绪事件（语气波动，只标语气不标内容）。
- 证据标准：用户主动表达才算；每条信号带原文片段（可 grep 回溯）+ 出处 + 日期；增量标记驱动不重扫。
- 偏好库：`../../evolution/偏好库/<域>.md`，四域（沟通与表达/编码习惯/交付与流程/工具与环境）；读-更新-写回的持久知识层。
- 三决策：候选偏好与既有条目比对后 新建 / 合并 / 跳过（源自 OpenViking，防重复膨胀）。
- 状态：生效（证据 ≥2 无反证）/ 观察中（孤条）/ 已过时（出现反向行为，保留不删）。
- 触发判据：同 skill 相关信号 ≥3 条同矛盾 / 生效偏好与 skill 行为冲突 / 用户点名 / Skill-Optimizer 调用 / 定期兜底（≥2 周或 ≥20 条）。
- 读轨迹定因：诊断必须读会话/日志/产物原文，禁只凭结果好坏下结论（源自 GEPA）。
- 进化建议单：目标+位置 / old→new / 依据信号 / 预期+风险 / 能力审计 / 回滚方式。
- 五护栏：语义不漂移 / 体积红线 ≤500 行 / 能力不丢（old-vs-new 审计）/ 确认后改 / 留痕可回滚（源自 hermes 护栏本地化）。
- 三档：保守（只出报告）/ 标准=默认（确认后改）/ 激进（P2 自动改+事后报，用户显式开启）。
- 进化台账：`../../evolution/进化台账.md`，每进化一条，只增不改；回滚靠 git。
- 可见性硬约束：偏好沉淀内容完整展示（标题+证据+正文逐条），禁只报数量（2026-09-11 用户全局约定）。
