# 进化台账条目模板

> 每次进化执行一条，追加进 `../../../evolution/进化台账.md`。只增不改；回滚靠 git，台账负责「为什么改」可追溯。

```markdown
### E-<序号> <日期> <目标 skill>（档位：<保守|标准|激进>）
- 触发信号：<偏好条目编号 P-x | issue 编号 | 信号月志定位 | 用户点名>
- 诊断结论：<轨迹原文说明了什么问题，定位到哪一层（触发/主流程/护栏/references）>
- 改动清单：
  - <文件:行区> old → new（一句话）
- 能力审计：old 清单 N 项 / new 清单 N 项，<无丢失|差异说明>
- 语义定位：改前「<一句话定位>」= 改后「<一句话定位>」（未漂移）
- 确认记录：<用户逐条确认日期 | 激进档 P2 免确认（事后报告编号）>
- 回滚方式：git revert <commit>；偏好条目已标「已反哺」，回滚时同步改回
- 同步状态：源仓库 ✅ / 安装副本 ✅（哈希校验 <日期>）
```
