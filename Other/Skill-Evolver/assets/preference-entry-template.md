# 偏好条目模板

> 每条偏好一个条目，写入 `../../evolution/偏好库/<域>.md`。域枚举：沟通与表达 / 编码习惯 / 交付与流程 / 工具与环境。

```markdown
### P-<序号> <一句话偏好>（状态：<生效|观察中|已过时>）
- 域：<沟通与表达|编码习惯|交付与流程|工具与环境>
- 内容：<用户希望 Agent 怎么做——可执行的判据，不是形容词>
- 证据链：
  - <日期> <出处（会话/文件）>：「<原文片段，可 grep 回溯>」
  - <日期> <出处>：「<原文片段>」（同类 ≥2 条才立「生效」；孤条先「观察中」）
- 频次：<同类表达次数>
- 关联信号：<信号/YYYY-MM.md 中的条目定位>
- 反哺记录：<已反哺 <skill 名> <日期> | 未反哺 | 不适用（纯用户画像）>
- 更新历史：<首次发现日期；历次合并/状态变更一句话>
```

## 状态语义

- **生效**：证据 ≥2 且无反向证据——进化触发的依据；
- **观察中**：孤条证据，等再出现一次同类表达；
- **已过时**：后续行为/表达与该偏好相反——保留条目标过时（不删），偏好演进有迹可循。
