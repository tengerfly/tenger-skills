# <错误模式简述：一句话点出「哪类坑」>

> 归属：`../../bug-patterns/` 错误模式池 ｜ 日期：YYYY-MM-DD ｜ 来源：Bug-Fix 收尾沉淀
> 依据：Bug-Fix 闭环 `.spec/bug修复/<日期>-<简述>/问题定位报告.md`（可追溯回真实案例）
> 原则：存「一类会再犯的错误」+ 防复发规则，不是单点 bug 记录。

## 基本信息

| 字段 | 值 |
|---|---|
| 根因类型 | 数据问题 / 状态问题 / 竞态并发 / 契约不一致 / 环境依赖（五选一为主） |
| 受益 skill | Backend-Tech-Design / Frontend-Tech-Design / Backend-Dev / Frontend-Dev（可多选） |
| 等级 | P0 / P1 / P2（同类再犯的破坏度） |
| 建议落点层级 | 错误表加行 / references 防复发清单 / Gate 预检项（从轻到重） |
| 状态 | 待提炼 |
