# 载体与结构零改动检查清单（Layout Freeze Checklist）

> 目标：核验设计稿是对布局清单的「忠实穿衣」——载体划分、页面区块、元素集合、跳转关系逐项一致，视觉阶段不得增删移结构；同时反查设计稿是否擅自加了无出处元素（防加戏）。
> 对照物：布局清单（`.spec/原型/布局清单.md`）或 UI-UX-Design 设计任务清单。

---

## 一、载体与页面完整性（查漏）

### 1.1 页面清单一一对应
- [ ] **独立页面覆盖**：布局清单的全部独立页面在设计稿中都有对应 HTML，无少页、无多页、无改名错位；
- [ ] **页面文件命名一致**：设计稿 HTML 文件名与布局清单页面文件名一致（`list.html` → `list.html`）；
- [ ] **端类型匹配**：视口 / 布局形态与布局清单端类型一致（Web 宽幅 vs 移动窄屏）。

### 1.2 区块与元素结构
- [ ] **每页区块结构一致**：区块数量、类型、位置关系（导航/侧栏/操作区/数据区/统计区…）与布局清单逐项一致；
- [ ] **组件类型一致**：表格还是列表、几张统计卡、几个 Tab、几个卡片——不多不少；
- [ ] **表格列定义一致**：列数、列顺序与布局清单一致；
- [ ] **表单字段一致**：字段名、控件类型、必填标识齐全，无增删字段；
- [ ] **弹框 / 抽屉宿主挂载一致**：与布局清单一致（宿主页面、触发入口、数量）；弹框抽屉以视觉区块存在于宿主 HTML 内，不单独成文件；
- [ ] **内容要素数量一致**：统计卡 4 张就是 4 张、列表项形态与布局清单一致（静态视觉稿以占位呈现不算缺）。

---

## 二、跳转关系一致性

- [ ] **入口按钮 → 去向一致**：设计稿中每个可跳转入口（导航菜单、按钮、行操作、卡片点击）的 href/去向与布局清单站点地图逐条对上；
- [ ] **无断链**：所有 `<a href>` 非空（完整 URL 或 `#hash` 占位均可，禁止空 `href` / `href="#"` 死链 / 相对路径）；
- [ ] **无孤儿跳转**：布局清单没有的跳转目标未出现；布局清单要求的目标全部可达（可达 = 有入口 + 目标页存在，真实业务跳转不要求）。

---

## 三、冗余元素排查（查多 · 防加戏）

### 3.1 无依据元素
- [ ] **多余按钮 / 操作入口**：页面上每个按钮、链接、操作图标都能在 PRD / 布局清单找到出处；PRD 未要求的（如多出的「导出」「批量删除」「收藏」）记为冗余问题点；
- [ ] **无依据区块 / 卡片 / 推荐位**：是否存在布局清单未定义却自行添加的统计卡片、通知栏、快捷入口、推荐区块、页脚版权等；
- [ ] **无依据装饰区块**：hero 大图、装饰性分区、空态插画等若 PRD / 布局清单未要求即记问题。

### 3.2 与内部门禁的关系
- UI-UX-Design 内部门禁自检「布局零改动」；本维度由评审**独立复核**，不从其门禁结论出发，以布局清单 + 设计稿源码为唯一证据。

### 3.3 分级建议
| 情形 | 严重度 |
|---|---|
| 核心载体缺失 / 多出影响还原基准 | P0 |
| 局部区块缺失 / 多出一个组件或按钮 | P1 |
| 纯装饰性冗余、无冲突 | P2 |
