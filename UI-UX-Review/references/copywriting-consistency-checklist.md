# 文案与字段一致性检查清单

> 对照 PRD（速查表优先）+ 布局清单。逐字一致、防杜撰、防加戏。

| 类别 | 检查项 |
|---|---|
| 标题/CTA | 页面/区块/弹框标题与 PRD 逐字一致；按钮语义严格区分，禁「OK/确定」替代具体动作 |
| 字段/表格 | Label、列名顺序、状态标签与 PRD 一致；占位符体现格式要求，禁 Lorem；反馈/空态/引导不杜撰 |
| 图形化表达 | 图标按钮有可读文字或 aria-label 对应原动作；超长字段截断不破坏危险词语义 |
| Mock 数据 | 真实自洽（时间/金额逻辑），单位正确，无乱码/假占位 |
| 防加戏 | PRD 未定义的 Toast/引导/CTA 记冗余；与 PRD 冲突升级 P0/P1；补充文案未标【设计假设】且未确认 → 记问题 |

分级：核心文案冲突/误导 P0/P1；纯多余 P2。
