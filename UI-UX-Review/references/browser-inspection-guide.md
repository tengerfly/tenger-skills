# 浏览器渲染与点击验证指引

> 检测顺序、两级行为、硬依赖报错文案见仓库根 `shared/browser-policy.md`（本 skill = 硬依赖）；本文件只保留本 skill 专属的渲染走查与点击验证规范。

## 一、渲染走查规范

- 静态服务渲染逐页截图，异常处截入 `screenshots/`；
- 渲染基线：真实渲染设计稿 HTML（非静态截图），验证规范落地与结构级可点击性。

## 二、点击验证规范

- 逐入口点击：真实 `<a href>` 或等价触发；像按钮却点不动 = 缺陷；
- 可点击性边界：只到「入口存在且可点、href 去向与站点地图一致」，不验业务逻辑。

## 三、硬门禁失败

- 立即停止，不产出评审文档（报错文案见 `shared/browser-policy.md` §四）。
- 静态源码审查是并行互证手段，不是缺工具时的替代。
