# 视觉规范一致性检查清单（Visual Spec Consistency Checklist）

> 目标：核查设计稿页面上的一切视觉值是否全部出自 design-system token——规范外的颜色/字体/间距/圆角/阴影/组件样式即缺陷。规范一致性是「风格统一、可复用、可交前端还原」的前提。
> 对照物：`.spec/设计稿/design-system.md`（归档副本；权威源 `.superdesign/design-system.md`）。

---

## 一、Token 落地（机械比对）

- [ ] **`:root` CSS 变量一致**：页面 `:root` 的 CSS 变量与 design-system §Token 汇总一致——无缺项、无私改值、无另起炉灶命名；
- [ ] **色值全可溯源**：页面出现的一切颜色都能在 token 中找到出处（grep `#[0-9a-fA-F]{3,8}`、`rgb()/hsl()` 与 token 表比对；允许的例外：token 派生的透明度写法）；
- [ ] **无「硬编码色」**：出现 token 表之外的色值（尤其霓虹/渐变/纯黑 #000 装饰）即记问题；
- [ ] **字号 / 字重只用规范层级**：标题/正文/辅助三级（或规范定义的阶）之外的字号字重即记问题；
- [ ] **间距符合 4px 网格**（或规范定义网格）：出现 3px/7px/11px 类脱离网格的间距即记问题；
- [ ] **圆角 / 阴影取规范定义**：无规范外圆角阶、无重阴影/光晕类非规范阴影。

---

## 二、组件规范一致性

- [ ] **组件样式符合规范 §组件**：按钮三态（默认/hover/disabled）、表格行高、弹框结构、badge 配色、输入框边框/聚焦态与组件规范一致；
- [ ] **组件不做「一次性设计」**：同一组件在不同页的表现一致（同一按钮风格、同类型状态标签同色），无同组件各页各改各的；
- [ ] **图标风格统一**：线性/面性同源图标集、同描边、无 emoji 当图标；
- [ ] **语义色使用正确**：成功/警告/错误/信息语义色对应正确业务语义（危险操作不用成功绿）。

---

## 三、字体与资源

- [ ] **字体家族与规范一致**：中英文字体 fallback 链与 design-system §排版一致，无页面私加字体；
- [ ] **品牌资产使用正确**：logo 位是真实品牌资产（非首字母/emoji/自造 SVG），图片引用为 `https://` 公网或 `data:`（无相对路径 / file://）。

---

## 四、反 AI 味 12 条（视觉规范延伸，逐条过）

- [ ] 无 emoji 图标（统一 SVG / iconify）；
- [ ] 无紫→蓝渐变默认背景；
- [ ] 无装饰性渐变光斑 / blob；
- [ ] 无「hero 大标题 + 三卡片 + CTA」模板结构（对照布局清单，不套模板）；
- [ ] 阴影克制、无过度玻璃拟态；
- [ ] 内容密度真实（贴近真实应用，不空旷留白）；
- [ ] 配色从产品定位推导，非常见「AI 蓝」默认；
- [ ] 字体层级分明；
- [ ] 无出处按钮一律不得出现（对照 PRD）；
- [ ] 无出处提示文案一律不得出现；
- [ ] 无出处区块/模块一律不得出现；
- [ ] 整体简洁大方、按钮克制。

> 分级建议：规范整体性被绕过（整页配色另起炉灶 / token 系统性偏差）→ P0；单组件/单值偏差 → P1；轻微视觉偏差（如一处阴影略重）→ P2。
