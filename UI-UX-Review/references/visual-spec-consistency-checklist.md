# 视觉规范一致性检查清单

> 对照 `.spec/设计稿/design-system.md`。一切视觉值须出 token。

## Token 机械比对
- :root 变量与规范一致，无缺项/私改/另起炉灶。
- 所有色值可溯源（grep #hex/rgb/hsl 与 token 表；token 派生透明度除外）。
- 字号字重只用规范层级；间距符合 4px 网格；圆角/阴影取规范定义。

## 组件与资源
- 组件样式符合组件规范（按钮三态/行高/弹框/badge/输入框）。
- 同组件跨页一致，无一次性设计。
- 图标同源同风格，禁 emoji；语义色对应正确业务语义。
- 字体链一致；logo 为真实资产；图片 https/data:，无相对/file://。
- 动效合规：时长对照 §6 档、曲线取自 §7 token（无 ease-in、常规 UI <300ms、弹层 / 抽屉类按档）；无答不出目的的动画（口径同设计门禁 §二）。

## 反 AI 味 12 条
无 emoji 图标/紫蓝渐变/光斑 blob/hero 模板/重阴影玻璃拟态/空旷密度/AI 蓝默认/层级不明/无出处按钮/提示/区块，整体克制。

分级：整体另起炉灶/系统性偏差 P0；单值偏差 P1；轻微偏差 P2。
