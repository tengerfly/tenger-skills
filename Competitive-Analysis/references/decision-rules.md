# 竞品分析决策规则（Decision Rules）

> 用途：竞品分析的「证据底线 / 反模式 / 监控节奏 / 量化评分」决策库。本 Skill 的「数据红线 8 条」优先级最高，本文件补「来源缺失标注 / 反模式 / 监控节奏 / 加权评分」。

---

## 一、证据标准（补充数据红线）

- 所有关于竞品功能/定价/策略的**事实声明必须可溯源公开来源**（URL + 访问日期）。
- 来源缺失时显式标注「[定价未公开]」「[数据缺失]」，**绝不编造**功能、证言、市场份额。
- 多源互证引 2–3 个代表源；不确定就标 limitation。

## 二、反模式（不要做）

- ❌ 只抄竞品营销话术，不交叉验证。
- ❌ 忽略间接竞品（替代品也是威胁）。
- ❌ 把功能列表当能力（有功能 ≠ 能用）。
- ❌ 不做定价研究、不做定位地图。
- ❌ 报告又长又描述性，无 actionable 洞察。

## 三、监控节奏

| 周期 | 扫什么 |
|---|---|
| 月度 | 新兴挑战者、相邻市场进入者 |
| 季度 | 潜在颠覆者、新技术/新模式 |
| 年度 | 整体复盘，重画定位地图 |

## 四、加权评分卡（差异化量化，借鉴 majiayu）

- **6 加权维度**：文档完整性 20% / 工具脚本质量 20% / 工作流覆盖 15% / 架构 15% / 自动化 15% / 参考深度 15%。
- **优先级公式**：`Priority = Impact×0.4 + Urgency×0.3 + Strategic×0.2 + (1/Effort)×0.1`。
- 输出：AHEAD / EVEN / BEHIND 判定 + ASCII 评分卡 + 特性对比表。

## 五、报告质量门禁（flight505 11 项，此处节选 7 项，上线前核对）

- 市场定义清 / 主要竞品已识别 / ≥3 直接竞品已画像 / 定位图已画 / 差异化已识别 / 所有来源已引 / 结论可行动。
