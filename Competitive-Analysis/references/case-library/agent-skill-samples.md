# 同类竞品分析 Skill 结构样本（Agent Skill Samples）

> 用途：优化本 Skill 结构时的借鉴范本（只借鉴组织方式，不搬运内容）。

---

## 一、majiayu000/claude-skill-registry competitive-analysis（评分卡范本）

- 6 加权维度（文档完整性/工具脚本/工作流覆盖/架构/自动化/参考深度）+ 优先级公式 + AHEAD/EVEN/BEHIND 判定。
- 借鉴点：加权评分卡 + 优先级公式（已融入 decision-rules §四）。

## 二、claude-office-skills/competitive-analysis（报告模板范本）

- 完整报告（执行摘要/市场概览/竞品画像/SWOT/定位矩阵/特性对比）+ 多格式输出（docx/xlsx/chart）+ 4 类分析（Quick Comparison/Full Profile/Strategic/Battle Card）。
- 借鉴点：报告模板结构 + 多格式输出。

## 三、briannavly/competitive-analysis-templates（证据标准范本）

- 三类模板（竞品深潜/战斗卡/定位图）+ 证据铁律（可溯源/禁编造/缺失标注）。
- 借鉴点：证据标准（已融入 decision-rules §一）。

## 四、flight505/competitive-analysis（质量清单范本）

- 上线前 11 项核对（市场定义清/≥3 直接竞品/定位图/差异化/来源已引/结论可行动）。
- 借鉴点：质量门禁（已融入 decision-rules §五）。

## 五、GapHunter（痛点闭环范本，动作型）

- 抓 G2/Capterra/TrustRadius/Reddit/GitHub Issues 六平台负面评论 → 语义聚类 → 对照自身 → 优先级路线图。
- 三阶段管线：harvest → cluster → cross-reference。
- 借鉴点：「抓评论痛点→聚类→对照自身」的痛点挖掘闭环，可做本 Skill 用户痛点子模块增强。
