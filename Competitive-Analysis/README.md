# 竞品分析 Skill（Competitive Analysis）

> 给定一个明确的产品想法，通过全球中英文数据驱动调研，客观呈现其在市场趋势 / 竞品优缺点 / 用户痛点 / 商业模式 / 技术可行性五个层面的竞争全貌，输出工业级竞品分析报告。**判断交给用户**，本 skill 不下可行性结论。

## 这是什么

把用户的产品想法调研成一份**工业级竞品分析报告**：锁定赛道、筛选竞品、全球双语检索、五层交叉推演，经 Pass Gate 门禁验收后落盘交付。

- **最终交付物料**：`Competitive-Analysis/.output/<主题>竞品分析/` 下双文档——`<主题>竞品分析报告.md`（11 模块主文档）+ `验收结果详细说明.md`（三段式 Pass Gate 验收评测）。
- **核心纪律**：一切结论有据可依，禁止编造，预测必须标注，多方口径并列呈现。

## 核心机制

### 五层分析框架

| 层 | 要回答的核心问题 |
|----|----------------|
| 市场趋势 | 这条赛道大盘多大、增速如何、值不值得进 |
| 竞品优缺点 | 对手是谁、强在哪弱在哪、横向对比差异化机会在哪 |
| 用户痛点 | 目标用户痛在哪、真实社媒中在抱怨什么、哪些需求未被满足 |
| 商业模式 | 竞品怎么赚钱、成本与客单价是多少、目标产品如何设计变现 |
| 技术可行性 | 能不能做出来、关键技术路径、数据与合规壁垒是什么 |

> 每层子维度详见 `references/dimensions.md`。

### 赛道自适应策略

按赛道特征自动调整调研与报告侧重点：大厂垄断红海（看 CAC / 下沉 / 价格带缝隙）、内容平台蚕食（看 UGC 碎片化 vs 结构化闭环）、法律灰区（看知产 / 资质 / 合同合规）、海外出海（调 GVR / Statista 研报 + Reddit / Trustpilot 槽点）、数据稀缺（多方口径并列 + Unit Economics 测算）。

### Pass Gate 测试门禁（输出前强制自检）

| 裁决 | 条件 | 处置 |
|---|---|---|
| ✅ PASS | P0=0 且 P1(Open)=0 | 准予落盘交付 |
| ⚠️ CONDITIONAL PASS | P0=0 但 P1(Open)>1 | 就地补齐 P1 后二次验证 |
| ❌ FAIL | 命中任一 P0（编造 / 混淆事实 / 缺核心表） | 一票否决，阻断输出 |

### 数据红线（8 条，最高优先级）

禁编造 / 数据可溯源 / 预测必须标示 / 多方口径并列 / 商业假设显式隔离 / 简洁不啰嗦 / 具体优先 / 测试门禁前置。详见 `SKILL.md`。

## 快速上手

- **触发**：用户给出产品想法并要做竞品分析 / 调研 / 对比（含间接表达「这个赛道竞争怎么样」）；想法成熟要直接写需求时改用 PRD-Design。
- **交付**：双文档落盘 `.output/<主题>竞品分析/`，控制台同步呈现核心提炼与 Pass Gate 裁决摘要。
- **已验证**：9 个跨行业场景（教育 / 办公 / 电商 / 待办 / 记账 / 宠物殡葬 / 旅游 / 做饭 / 健身）全部 Pass Gate 通过。
