# 前端技术方案评审检查清单

> 标准：FTDD 能否完整承接 PRD + 原型（结构）+ 设计稿（视觉，有则）+ TDD 且内部闭环。不关心数据库/表结构/服务端实现。

| # | 维度 | 不通畅情形 |
|---|---|---|
| FE-T1 | 页面承接 | 原型页面 FTDD 未列（漏做）；FTDD 页面原型没有（凭空）；职责/路由/模块标注缺失；**有设计稿时逐页未对应设计稿稿源** |
| FE-T2 | 需求承接 | PRD 交互无组件/hooks 承接；FTDD 组件无需求来源；AC 与测试脱节 |
| FE-T3 | 交互闭环 | 操作无反馈；反馈后无流向；断头/无头链路 |
| FE-T4 | 状态覆盖 | 空/加载/成功/失败/边界态缺失 |
| FE-T5 | hooks 数据流 | 数据无源或无消费；hooks 间断链；逻辑未下沉 hooks |
| FE-T6 | fetch 对接 | 调用未定义接口（P0）；后端接口前端未消费（孤儿）；方法/路径/入参出参不一致（P0/P1） |
| FE-T7 | 模块边界与关联 | 关联图与模块文档单边缺失；关联类型/方向不明；页面组件归属打架 |
| FE-T8 | 视觉基准承接 | 有设计稿但 §8.6 未写 token 来源 / 未登记 §7 token 条数（搬运对账基线缺失）；组件拆分与设计稿视觉结构不符；无设计稿未声明视觉基准降级 |
| FE-T9 | 越界 | 写了数据库/表结构/服务端逻辑/中间件/技术选型（P2） |
