# 后端技术方案评审检查清单

> 标准：TDD 能否完整承接 PRD 且内部闭环。基线：PRD（先读速查表建索引，按锚点回原文）。不关心前端页面/组件/视觉。

| # | 维度 | 不通畅情形 |
|---|---|---|
| BE-T1 | 需求承接 | 需求/AC 无 TDD 承接（漏做）；TDD 设计无需求来源（凭空）；AC 与测试用例脱节 |
| BE-T2 | 数据模型 | 对象缺表；PRD 属性缺字段；字段要素不完整；数据规则未承接；同对象多表且不一致 |
| BE-T3 | 状态机 | 死循环；无终态；流转无触发；非法逆向未定义；与 PRD 状态不一致（P0） |
| BE-T4 | 流程 | 断头/无头流程；图无终态；模块边界断链 |
| BE-T5 | 接口设计 | 缺入参/出参/错误码；PRD 隐含能力无接口；调用关系不清 |
| BE-T6 | 模块边界与关联 | 关联图与模块文档单边缺失；关联类型/方向/产物不明；应做不应做缺失 |
| BE-T7 | 异常与边界 | 并发/幂等、越权、超限、空数据、失败恢复未定义 |
| BE-T8 | 越界 | 写了前端控件/组件/视觉/路由实现（P2） |
