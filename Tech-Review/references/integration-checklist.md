# 前后端关联一致性检查清单

> 标准：前后端方案的接口/字段/状态枚举/权限逐项可对接、数据流端到端闭环。归因：接口未定义→后端；未消费/调错→前端；命名冲突→双方。

| # | 维度 | 不一致情形 |
|---|---|---|
| IT-1 | 接口契约 | 调的接口后端没有（P0）；方法/路径不一致（P0）；入参/出参字段不一致（P1）；错误码/结构不一致（P1） |
| IT-2 | 数据模型 | 命名风格无转换约定；类型不一致（金额分 vs 元）；必填/可空相反；枚举无映射 |
| IT-3 | 状态/枚举 | 状态数不一致；同状态叫法不同；文案/颜色与状态值对不上 |
| IT-4 | 数据流 | 后端无出口；前端无消费；异步谁触发谁接收未对齐；长任务中间态/终态未对齐 |
| IT-5 | 权限/错误 | 后端校验前端无对应路由/显隐；错误码无拦截/提示；token 过期刷新策略不一致 |
| IT-6 | 覆盖双向 | 前端需要的后端没有（P0）；后端提供前端不用（P1）；接口粒度不一致未写聚合方案 |
