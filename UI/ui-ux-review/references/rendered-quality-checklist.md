# 视觉呈现与可交付质量检查清单

> 差异化价值：真实渲染 + 结构级可点击。边界：不要求真实业务跳转/数据/弹框开合。

## 一、渲染健康
- 每页可打开、无白屏；console 零报错/无资源 404；样式完整加载；资源可达（https/data:）；无层级遮挡。

## 二、结构级可点击（核心）
- 应跳转入口真实可点（a href 或等价），点击有反应。
- 死元素（像按钮但无反应）记缺陷。
- href 去向与站点地图一致。
- 弹框/抽屉入口存在且宿主含视觉区块；下拉/菜单内入口（含头像菜单）可达对应稿。
- 无空/# 死链；纯展示元素无点击误导即不算问题。

## 二附 评审稿源一致性
- 评审对象 = 用户入口指向的云端稿（p.superdesign.dev/draft/<id>）。
- README 标「本地直编/待回传/云端旧版」→ 记缺陷；抽验入口 href 的 draftId 与 README 一致且为最新；迭升新增面板时整条入口链确认为新版。

## 三、渲染与规范
- 屏幕视觉与 design-system 意图一致；目标视口无错乱；响应式断点致命错乱才 P0；hover 无错误。

## 四、截图
P0/P1 缺陷逐条截屏，命名规范。

## 五、分级
主流程入口不可点/大面积白屏/弹框无入口 P0；单死元素/局部 404/单页报错/遮挡 P1；次要瑕疵 P2。

## 六、Nielsen 十项（主观体验补充）
状态可见性 / 系统与现实匹配 / 用户控制与自由 / 一致性与标准 / 错误预防 / 识别优于回忆 / 灵活高效 / 美观简洁 / 错误识别恢复 / 帮助文档。发现与三源冲突按自洽裁决；无法客观指认的「感觉不对」不记问题。

## 七、跨页不变量
- 全局组件全站一致（容器宽度/内部排布/激活态），禁逐页漂移。
- 限宽页内容列 = 顶栏列同宽同中心；禁内部二次窄列；全宽页铺满。
- 补 ≥1440/1920 宽屏截图核验断点放大与居中。
- 中文 N 字 × 字号 ≤ 容器宽，防折行溢出。
- 只改某页全局组件 → 回全站基线按内容区策略重做。

### 本节怎么执行（2026-09-24 补；此前只有规则没有动作，导致连续多轮"全绿"却漏掉整类问题）

**必须用真实浏览器逐页量测，源码里存在宽度规范文字不构成证据。** 每页取三值横向比对，产出**跨页宽度实测表**（逐页一行，随本维度报告落盘，是本节的唯一证据产物）：

| 量什么 | 取值方式 | 判据 |
|---|---|---|
| 顶栏内容行 | 读 `getComputedStyle(topbar)` 的 `paddingLeft/Right` 推出内容行内缘 | 作为对齐基准 |
| 主内容列 | **最外层带 `max-width` 的容器**（勿误抓全宽外壳 `main`/`.ds-main`——它常是 100% 宽，会得出"全部对齐"的假绿；也勿用子元素文字极值，会出假红） | 与顶栏内容行同宽、同中心、左缘差 ≤2px |
| 跨视口 | 至少 1440 与 1920 两档下主内容列宽度 | 放大规则全站一致，不得某页不跟随 |
| 二次窄列 | 遍历 `maxWidth !== 'none'` 且宽 >200px 的元素，按祖先链分组 | 同一祖先链上 ≥2 个限宽容器且中心差 >2px 即命中（豁免见下） |

**三类不算命中**（全站唯一枚举，与设计门禁 `../../ui-ux-design/references/self-write-review-gate.md` §2「二次窄列的三类豁免」同一份，不得各自增删）：

1. 已登记为栅格列轨的内层列；
2. 组件内部排版行宽（如 `max-width: 44ch` 类可读性约束）——依 `../../ui-ux-design/references/self-write-sop.md` §三「尺寸规则、布局比例和原生浏览器必要值不机械当成待新增的品牌 token」；
3. 注释层样张框（仅示意用途、不属交付页）。

- 量测脚本按需现写：用开工预检通过的浏览器工具（`getComputedStyle` + `getBoundingClientRect`），表头固定为 `页面 | 顶栏内容行内缘 x/宽 | 主内容列 x/宽/中心 | 1440 与 1920 主列宽 | 命中的二次窄列 | 结论`；不预设固定脚本文件名。
- 命中即按**跨页共性问题**合并成一条上报（不逐页开单），并标注收敛方案属设计方向决策、须用户裁决。
- 未跑本表 → 本节各条一律标「未验证」并写入交付边界，**不得计入"已查"**。
