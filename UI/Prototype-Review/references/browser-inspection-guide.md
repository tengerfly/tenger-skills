# 浏览器走查与截图指引

> 检测顺序、两级行为、硬依赖报错文案见仓库根 `../../../shared/browser-policy.md`（本 skill = 硬依赖）；本文件只保留本 skill 专属的截图规范与门禁动作。

## 一、截图规范

- 只对 P0/P1 关键缺陷截图；纯文案/字段差异用代码行号比对，不截。
- 存 `.spec/原型评审/screenshots/`，命名 `ISSUE-[编号]-[页面]-[问题].png`。
- 报告中用相对路径内嵌：`![缺陷截图](./screenshots/...)`。

## 二、硬门禁失败

- 立即停止，不产出报告/任务清单（报错文案见 `../../../shared/browser-policy.md` §四）。
- 静态源码审查是并行互证手段，不是缺工具时的替代。
