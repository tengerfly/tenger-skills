## 一、决策四问（每处动效逐问过，答不全就不加）

**1. 该不该动？看用户见到它的频率：**

| 频率 | 决策 |
|---|---|
| 100+ 次/天（快捷键、命令面板、高频切换） | 不做动画，永远 |
| 每天数十次（hover 反馈、列表导航） | 删除或大幅减弱 |
| 偶尔（弹框、抽屉、Toast） | 标准动画 |
| 罕见 / 首次（引导、反馈、庆祝） | 可加愉悦感 |

- **键盘触发的动作禁动画**——高频重复，动画只会让操作显得慢、有延迟感。

**2. 目的是什么？** 有效目的只有 5 类：空间一致性（进出同向，滑动关闭才符合直觉）／状态指示（提交后按钮变形）／解释（演示功能如何工作）／反馈（按压确认界面听到了）／防止突兀（出现消失无过渡像坏了）。答不出目的的动效 = 装饰，与反 AI 味「动效克制」冲突，砍掉。

**3. 用什么缓动？**

| 场景 | 缓动 |
|---|---|
| 进入（出现 / 弹出） | ease-out（起步快，响应感） |
| 屏内移动 / 变形 | ease-in-out |
| hover / 颜色变化 | ease |
| 恒速（进度条、跑马灯） | linear |

- **UI 禁 ease-in**：起步慢，用户最关注的那一瞬最迟滞，同样的 300ms 会「感觉更慢」。
- 内置曲线偏弱，用 §三 自定义曲线。

**4. 多快？** 时长按 §三 分档；**常规 UI 微交互 <300ms；弹层 / 抽屉类按档放宽至 ≤500ms**。

## 二、动效强度档（随风格决策定档）

| 档 | 特征 | 适用 |
|---|---|---|
| 静态（1-3） | 无自动动画，仅 hover / active 状态过渡 | 数据密集后台、金融政务、效率工具 |
| 克制流动（4-7） | 进出场过渡 + 反馈动效，值全部 token 化 | 通用企业产品（默认档） |
| 编排（8-10） | 页面级入场编排、滚动联动、微交互细节 | 营销页、消费级产品（企业项目少用） |

- 档位在步骤 4 风格决策时随「交互气质」一并定，写进 §6；**页面内实际动效必须与档一致**——静态档出现编排动画、编排档页面完全不动，均门禁不通过。

## 三、曲线与时长 token（填 §7）

自定义曲线（比内置曲线有力）：

```css
--ease-out: cubic-bezier(0.23, 1, 0.32, 1);      /* 进入 / 响应反馈 */
--ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);  /* 屏内移动 / 变形 */
--ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);   /* 抽屉 / 底部弹层 */
```

时长分档（按元素）：

| 元素 | 时长 |
|---|---|
| 按钮按压反馈 | 100-160ms |
| Tooltip、小浮层 | 125-200ms |
| 下拉、选择器 | 150-250ms |
| 弹框、抽屉 | 200-500ms |

## 四、落地口径

1. **§6 动效原则**填四项：时长档（对齐上表）／缓动（用 §三 曲线，禁 ease-in）／强度档／原则句（只动「进出场 + 反馈」）；
2. **§7 增加 3 行曲线 token**（`--ease-out` / `--ease-in-out` / `--ease-drawer`），随 token 汇总一并登记条数（下游对账口径不变：条数 = 本表条数）；
3. **生成稿动效范围**只含进出场与反馈，不做装饰性动画；高频 / 键盘触发位置不加动画；
4. **步骤 8 门禁动效检项**：动效强度与档一致；无答不出目的的动画；常规 UI 动效不超 300ms（弹层 / 抽屉类按档）；曲线只取 §7 token，不手写内置 ease 默认值。
