# 视觉还原比对清单

> **基准口径**：视觉应然 = **设计稿**（有设计稿时，逐项与设计稿 HTML 比对）；低保真原型只判「结构/存在性」，**不作视觉基准**（无设计稿才回退原型并标注降级）。
> 双向：设计稿有实现页没有/不对（漏）；实现页多出（加戏）。通道 A 用 token 机械比，B 用像素目测并标注。

## 一、布局/尺寸
骨架、区块对齐、栅格、响应、多余区块；内距/宽高/行距；禁魔法间距（间距值须落在设计稿 token 的 4px 网格内）；固定/悬浮元素（吸顶导航、悬浮操作栏）不遮挡内容（焦点遮挡详见交互清单）。

## 二、颜色
主色/语义色/背景与**设计稿**一致；走 token；对比度用 axe-core 算（WCAG 正文 ≥4.5:1），不靠观感。

## 三、字体/圆角/阴影/描边
字号字重层级（标题/正文阶梯拉开，全部同级即问题；用到的值能在 **design-system token** 中找到出处）、字体回退；圆角/阴影/描边与 token 一致。

## 四、层级/遮罩
浮层相对层级正确；z 不被盖；遮罩深浅与点击区域一致。

## 五、图标/图片
图标同套同风格（取自设计稿同套资源）；头像裁切一致；空态插画/加载存在且风格一致；图片有显式尺寸，加载不引起可见布局跳变。

## 六、状态（10 大 UI 状态双向对照）
- 设计稿定义的状态（空/错/加载/禁用/403/断网/流式等，出处 design-system §5.10）**逐态还原一致**：占位结构、插画、CTA、Banner 位置、打字机光标等；
- 实现页出现设计稿没有的状态表达 = 加戏（同双向原则）；
- 设计稿未定义且 FTDD 未要求的状态，不作还原度评判（归 Testing 功能覆盖）；
- 表单/组件级状态与设计稿一致；暗色下对比清晰；窄屏重截无错位/横向滚动。

## 七、token 速查表（通道 A 必做：搬运对账）
通道 A 摘录 design-system §7 的 color/typography/spacing/radius/shadow，与实现侧 `styles/variables` **逐条对账**（条数/值/命名）并在实现页 computed style 上逐项断言、打勾。**缺项、手抄错值、间距脱离 4px 网格即视觉偏差**（详规见 SKILL §4.2.1）。

## 八、输出
每差异记一行 + 实现页截图 + **设计稿**并排截图；整体走样 P0、局部明显 P1、像素微差 P2。
