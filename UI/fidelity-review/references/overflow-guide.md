# 超长文案 / 样式错乱专项

> 用真实 + 极端长文案替换动态文本位，验证是否溢出/遮挡/崩版。属边界造条件三类之一（长文案/暗色/窄屏）。

## 一、文本位
标题、按钮、表格列、列表项、表单值、标签、提示、数字/单号、面包屑/导航。

## 二、构造输入
1. 真实业务最长样例（PRD/接口 mock；无则贴近业务）。
2. 极端：无空格长串（横溢）、中文长句（纵折）、混合标点、长 URL/邮箱/单号。替换范围经 SKILL 步骤 2 比对范围清单确认（Testing 内嵌场景即其 Scope Gate）。

## 三、判定
- 溢出/遮挡/撑崩 → 问题（遮挡升级 P1/P0）。
- 换行难看 P2；无省略截断 → 问题；两行自然折行且整齐 → 通过。

## 四、改法
nowrap+ellipsis；line-clamp 限行；table-layout:fixed+min-width:0；flex min-width:0；break-word；tooltip 承接；卡片定高或自适应；等宽字体+省略；小屏再验。

## 五、截图
替换前后各截一张，命名 `<页面>_<文本位>_长文案_<序号>.png`；问题必截崩坏现场。

## 六、常见错误
漏表格/按钮、压力用例无来源、见换行即 P0、只报不改、截通过项 → 纠正。
