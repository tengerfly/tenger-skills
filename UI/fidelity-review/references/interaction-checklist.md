# 交互还原走查清单

> 范围：全量可点元素 + 普适交互。只验是否还原可用，不验业务逻辑。截图无法表现时附操作步骤。
> 两路配合：截图视觉验证 + snapshot 读结构驱动交互。

## 一、可点性与反馈
- 盘点并逐点全部可点元素：按钮/链接/输入/下拉/开关/勾选/Tab/分页/卡片/行操作/图标/面包屑/导航。
- 验证点击有视觉或行为反馈；死元素 P0/P1。
- 禁用态真实 disabled；不该禁用的误禁记问题。

## 二、交互方式
- 触发方式、跳转链路、hover/active/focus 与设计稿一致。

## 三、普适交互
- Tab 即时切换且有选中态。
- 弹框/抽屉/下拉：开→关闭环；重复点击不叠层。
- 表单：必填/格式错误提示、提交 loading/防重复。
- 分页/加载/筛选/折叠/开关可用。

## 四、差异记录
缺失（点了无反应）/走样（方式变了）/多余（擅自加交互）/状态错（反馈不对）。

## 五、悬浮层专项
- 触发器→浮层→目标项通路连续，有间隙即 P1。
- 浮层目标可点；下拉内入口到达对应载体（无去向 P0/P1）。
- 浮层不越过 overflow/sticky 边界；z 高于同级。
- hover 态截图存证；动态消失附操作步骤。

## 六、动效还原（页面存在动效时）

- 时长 / 缓动与 `design-system.md` §6/§7 token 一致（不超档、无 ease-in、常规 UI 动效不超 300ms、弹层 / 抽屉类据档）；
- 可打断：快速连点 / 连开浮层不卡顿、不重启归零（Toast 连发、开关快速切换）；
- 浮层缩放方向（transform-origin）与触发点一致；弹框居中除外；
- reduced-motion 下位移 / 缩放类动效消失且不崩（透明度 / 颜色过渡可保留）；
- hover 动效有 `@media (hover: hover)` 门控（触摸设备不误触）；
- 无 `transition: all`、无动画化布局属性（width / height / top 等）——静态读样式即可判定。

## 七、界面质量可见项（a11y / 表单 / 排版）

- 焦点可见：键盘 Tab 走一遍主流程，焦点环不丢、不被吸顶元素遮挡；
- 表单 label 可见且关联；错误内联在字段旁；placeholder 以 `…` 结尾；
- 加载态文案以 `…` 结尾；省略号 / 引号规范（`…` 与弯引号，非 `...` 与直引号）；
- 吸顶 / 悬浮元素不遮挡内容与焦点。

## 八、输出
页面/元素/预期/实际/步骤/严重度/建议；拿不准该不该有时回布局清单或 PRD，仍不定标假设。
