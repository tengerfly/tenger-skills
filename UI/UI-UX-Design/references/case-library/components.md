# 可复制组件/区块库（Components）

> 定位：案例库·组件类。「复制即拥有源码」的组件范式资源——做**组件解剖**（结构/状态/变体/无障碍）与区块范式参考。
> 边界：本 skill 输出纯 HTML 设计稿，不直接依赖这些库；学的是组件的组织方式、状态完备性与视觉范式。

| 名称 | 链接 | 许可 | 案例库价值 |
|---|---|---|---|
| shadcn/ui | https://ui.shadcn.com | MIT | 复制即拥有源码的组件范式，案例库「组件解剖」样板 |
| Radix UI（headless） | https://www.radix-ui.com | MIT | 无样式 + 无障碍的底层原语，学「行为/可访问性」而非外观 |
| Magic UI | https://magicui.design | MIT | 150+ 动效组件（光束、Bento、跑马灯），落地页/营销区范式 |
| Aceternity UI | https://ui.aceternity.com | 免费核心+付费 | 200+ 高冲击视觉组件（3D 卡片、光晕、粒子背景） |
| HyperUI | https://www.hyperui.dev | MIT | 纯 HTML+Tailwind 免依赖组件，复制即用 |
| Origin UI | https://originui.com | 免费 | 进阶版 shadcn 组件（时间线、富对话框等） |
| Cult UI | https://cult-ui.com | MIT | 动效组件 + AI SDK 交互模式 |
| awesome-ui-components | https://github.com/awesomelistsio/awesome-ui-components | — | 组件库/设计系统/无头 UI/动效/图标 分类总索引 |
| awesome-ui-resources | https://github.com/al-husayn/awesome-ui-resources | — | 现代 UI 资源中枢：组件块、动效、设计系统一站导航 |

**沉淀格式**：每个组件块存「预览图 + 源码路径 + 依赖 + 何时用」；以 shadcn/Radix 系做「标准解剖模板」（结构 → 状态完备性：default/hover/active/disabled/focus → 无障碍要点）。
