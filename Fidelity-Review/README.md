# Fidelity-Review —— 页面还原度评审 Skill

> **状态**：✅ 定稿
> **定位**：只审不改（截图必证 + 成因必写 + 每条附修改建议）。对照 **UI 设计稿**逐页评审**前端实现页面**，找「设计长这样、实现变样了」的视觉/交互/超长文案问题。

## 一、这是什么

一个把**前端实现页面**（本地运行或已部署 URL）与 **UI 设计稿**（双通道基准：优先 `.spec/设计稿/`，缺失接受外部设计稿）逐页比对的还原度评审 Skill。它不改任何代码，只输出三类问题的分级清单（每条含截图、成因、修改建议）：**视觉还原**（布局/层级/颜色/字号/间距等与设计稿不一致）、**交互还原**（该点点不动、交互方式变了、普适交互不对）、**超长文案专项**（设计稿短文案好排版，实现页接长文案就溢出/错乱）。

**一句话原则**：审出还原差异，不改一行代码；**样式问题必截图，每条必说怎么改**；还原度只对「实现页 vs 设计稿」负责。

## 二、核心设计

| 项 | 决定 |
|----|------|
| 名称 | `Fidelity-Review`（中文「页面还原评审」） |
| 输入 | 前端实现页面（URL/路由清单）+ UI 设计稿基准（双通道）+ 可选原型/PRD（交互存在性辅助） |
| 输出 | 独立模式：`页面还原度评审报告.md` + `任务清单.md` + `screenshots/`；Testing 模式：轻量问题清单 |
| 三大评审面 | 视觉还原 / 交互还原（全量+普适项）/ 超长文案专项 |
| 域界 | 只审不改；只评还原度；不评业务逻辑正确性（归 Testing）、不评接口契约/架构（归 Code-Review）、不评设计稿本身（归 UI-UX-Review） |
| 双模式 | 独立调用（任务清单闭环交 Frontend-Dev）/ Testing 调用（就地轻量清单供汇总，不建任务清单） |
| 浏览器工具 | 硬依赖（Playwright → browser-use → 其他；全无 → 报错等安装） |

## 三、与仓库 skill 的边界

| Skill | 关系 |
|---|---|
| UI-UX-Design | 通道 A 基准生产方（`.spec/设计稿/`）；设计稿自身缺陷回它修改 |
| Frontend-Dev | 主要被审对象 + 主要修改方；其 fidelity-guide 是开发自查，本 skill 是第三方独立还原验收 |
| UI-UX-Review | 不重叠：它评设计稿本身 vs PRD/布局清单/规范（设计阶段），本 skill 评实现页 vs 设计稿（开发后） |
| Code-Review | 不重叠：它评逻辑/代码层，本 skill 只评页面样式/交互还原 |
| Testing | 被调用：Testing 样式测试环节调用本 skill 做 UI 还原度检查 |

## 四、评审流水线

```
输入解析（页面 + 双通道设计稿基准）→ 浏览器硬性预检 → 页面清单×基准映射（用户确认范围）
    → 双开截图走查 + 点击验证 → 视觉还原比对 + 交互还原走查 → 超长文案专项
    → 分级报告 → 双模式收尾（独立=任务清单 / Testing=轻量清单）
```

## 六、严重度分级

| 严重度 | 含义 | 典型情形 |
|--------|------|---------|
| **P0 致命** | 整体结构/主视觉严重不符、核心入口点不动、长文案大面积崩坏阻断使用 | 列表页实现成卡片流、提交按钮点了没反应、表格被长文本撑破 |
| **P1 重要** | 局部布局/间距/字号/颜色明显偏差、单元素不可点或交互方式不同、长文案溢出破坏局部 | 弹框确认按钮点不动、按钮文案不同、卡片标题两行排版崩开 |
| **P2 建议** | 像素微差、非关键视觉细节、可接受的轻微换行 | 间距差 2px、图标色偏一档 |

> 本 Skill **不做通过/不通过裁决**，只输出分级问题清单；是否修改、由谁修改，交用户决策。

## 七、评审铁律

1. 只审不改；
2. 截图必证（一切样式/视觉/溢出问题必须配浏览器截图）；
3. 成因必写（推不出标「成因未明」，禁臆造）；
4. 方向明确（每条附修改建议 + 指定修改方：实现问题→Frontend-Dev；设计稿缺陷→UI-UX-Design）；
5. 浏览器工具硬性前置（全无 → 报错等安装，不静默降级）；
6. 只对「还原度」负责（业务逻辑/接口契约/架构归 Testing/Code-Review）。

## 八、产出物归档

独立模式评审产物统一放被开发项目 `.spec/页面还原评审/`；Testing 场景就地向 Testing 交轻量清单（不落本 skill 独立目录）。
