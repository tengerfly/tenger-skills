# UI 还原度检查问题清单（Testing 场景 · 就地输出）

> 用途：当 `Testing` 内部调用 Fidelity-Review 做「UI 还原度检查」环节时，本 skill **就地**输出此轻量清单交 Testing 汇总进其测试问题文档（`.spec/测试/测试问题文档.md`）。
> **区别于独立模式**：不生成 `.spec/页面还原评审/任务清单.md`、无状态机、无修改方闭环——状态与裁决由 Testing 统一管理。

> - **编号**：`UI-xx` 前缀，便于 Testing 汇总时并入（Testing 可改为其自有缺陷号）；

## 3. 边界备注

- 本清单只覆盖「实现页 vs 设计稿」的还原度问题；业务逻辑、接口契约、架构问题不属于本环节，由 Testing / Code-Review 各自负责；
- Testing 汇总时如与自身功能用例冲突，以 Testing 文档为准并注明来源 = Fidelity-Review。
