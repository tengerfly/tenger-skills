# 页面还原度决策规则（Fidelity-Review Decision Rules）

> 用途：还原度评审的「量化阈值 / 容忍度分级 / 闭环次数 / token 绑定 / 交互量化」决策库。本 Skill 六大铁律（截图必证/成因必写/方向明确/只审不改）优先级最高，本文件补「量化」维度。

---

## 一、像素偏差容忍度分级（行业经验值）

| 元素类型 | 容忍度 | 说明 |
|---|---|---|
| 文本 text | 3–5px | 字体渲染差异可接受 |
| 纯色块 solid | 0–1px | 必须几乎零偏差 |
| 渐变/背景 gradient | 2–3px | 抗锯齿与混合差异 |
| 边框/圆角 | 1px | 精确 |

- 触发修复阈值：任何元素偏差 >1px 且肉眼可见即触发回修。

## 二、断点覆盖（响应式）

- 至少覆盖 375 / 768 / 1024 / 1280 / 1440 五个断点，移动/平板/桌面逐档核对。

## 三、pixelmatch diff 阈值

- Web 页面 **0.5%**；PDF/长图 **1.0%**（超出即标偏差百分比）。

## 四、闭环次数（与轮次上限分工）

- implement → render → snapshot → compare → fix 单轮修复**最多 5 次 attempts**，超次报告未达标区域并暂停。
- 与本 Skill 铁律「轮次上限 3」分工：attempts = 单次修复的尝试次数；轮次上限 = 评审-修复循环轮数。

## 五、设计 token 绑定（治本，防魔法值）

- 颜色/间距/字号/圆角抽象成 Design Token（CSS 变量/Style Dictionary），实现只引用 token 不写死数值。
- 审查时比对「实现 token 值」vs「设计稿 token 值」，偏差即告警——从源头消除魔法值偏差。

## 六、交互还原量化（双轨）

- 「长得像」= 视觉回归（Figma/设计稿 vs 实现 → 像素 Diff）。
- 「动得对」= 微交互量化：过渡时长误差 ≤50ms、缓动函数匹配、状态切换可见性一致。

> 出处：lobehub visual-pixel-perfect、hbddjk 三阶校验、CSDN「像素之眼的自动化」。
