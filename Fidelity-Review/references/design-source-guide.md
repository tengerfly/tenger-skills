# 双通道设计稿基准获取与映射细则（Design Source Guide）

> 用途：确定本次评审的「UI 设计稿基准」来源（通道 A/B），并把「实现页 ↔ 设计稿页」逐页映射，为截图并排比对做准备。

---

## 一、通道判定（D-02 双通道）

### 通道 A：`.spec/设计稿/`（优先）

检查被开发项目根目录是否存在 `.spec/设计稿/`：

```
<项目>/.spec/设计稿/
├── README.md               # 页面清单 + 版本 + 输入来源（UI-UX-Design 产物）
├── design-system.md        # 设计规范副本（token：色值/字号/间距/圆角/阴影/组件）
├── <页面1>.html            # 各页定稿 HTML（Tailwind CDN，可浏览器打开）
├── <页面2>.html
└── screenshots/            # UI-UX-Design 归档时的关键态截图（可选参考）
```

- 存在且含对应页 HTML → 用通道 A，取：
  - **视觉基准**：各页 HTML（浏览器渲染）；
  - **规范基准**：`design-system.md` token（机械比对）；
  - **页面清单**：README 的页面/载体清单。
- 通道 A 的页面文件若与实现页路由**数量/名称对不上** → 停下向用户确认映射或补齐（不猜测）。

### 通道 B：外部设计稿（A 缺失时）

- 向用户索取：Figma 导出图 / PNG / 设计平台链接的静态导出 / README 内嵌设计图；
- 每页设计图命名/顺序与实现页路由对应；无命名规则时请用户指明逐页对应；
- 通道 B **无 token 可对照**：视觉按像素目测 + 刻度换算（设计图标注的 px 与实现页 computed px 对照）；
- 报告与清单必须标注 `基准 = 外部设计稿（通道 B）`，不得冒充通道 A 的 token 一致性结论。

### 通道判定流程

```
读 .spec/设计稿/（存在?）
├─ 是 → 通道 A：读 README 页面清单 + design-system.md token 速查 + 各页 HTML
└─ 否 → 通道 B：向用户要外部设计稿，确认逐页映射；标注通道 B
```

## 二、页面映射矩阵

对每个评审页面建立一行映射（先经用户确认范围再执行）：

| 实现页（路由/URL） | 设计稿对应文件/图 | 载体类型（页/弹框/抽屉/表格/卡片） | 视口（桌面 1440 / 平板 768 / 移动 375…） | 基准通道 |
|---|---|---|---|---|
| `/orders` | `orders.html`（A）/ `orders.png`（B） | 页面 | 1440 + 375 | A/B |
| `/orders/:id` | `order-detail.html` | 页面 | 1440 | A/B |

要点：
- **弹框/抽屉/局部载体**：若设计稿把弹框/抽屉独立成 html/图，映射到实现页对应弹框（触发入口所在页）；
- **同页多视口**：用户指定重点视口（通常桌面 + 一种窄屏），都列进矩阵；
- **实现页无对应设计稿**（如纯新增页）：标记「无基准页」，仅做健壮性与普适交互检查，不评还原（需向用户说明）。

## 三、辅助基准（可选，交互存在性判定用）

当「某交互在实现页有没有/该不该有」从设计稿无法推断时，按序回溯：
1. `.spec/原型/布局清单.md`（Prototype-Design 产物，载体划分 + 跳转关系）；
2. `.spec/PRD/VN/`（先读 `PRD速查表.md` 定位交互/状态所在模块，再按锚点回原文取描述）；
3. 仍无定论 → 标【设计假设】交用户裁决。

> 辅助基准只用于「该交互是否存在」的判定，**视觉还原仍以设计稿为唯一基准**。

---

## 四、启动实现页（可运行性前置）

- 本地工程：读项目 README/package.json 拿启动命令 → 起 dev server → 确认 `http://localhost:{{port}}` 各路由可达；
- 部署地址：直接用用户给的 URL；
- **页面打不开 / 启动失败** → 停下反馈（环境问题），不硬评审；阻塞时向用户要可访问地址。

---

## 五、常见错误对照

| 错误 | 纠正 |
|---|---|
| 项目里其实有 `.spec/设计稿/` 却去用外部稿 | 先探目录，A 存在则优 A |
| 用通道 B 下结论「token 不一致」 | B 无 token，只能目测；报告标注基准 |
| 映射对不上还硬评 | 停下请用户确认逐页映射 |
| 忘记把弹框/抽屉单列载体 | 弹框/抽屉是还原重灾区，必须独立比对 |
| 实现页没有设计稿对应页 | 标「无基准页」，只做健壮性+普适交互检查并说明 |
