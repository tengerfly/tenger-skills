# 视觉还原比对清单（Visual Fidelity Checklist）

> 用途：逐页核对「实现页」与「UI 设计稿」在视觉呈现上的一致程度。
> 双向核对：既查「设计稿有、实现页没有/不对」（漏还原），也查「实现页多出设计稿没有的」（加戏）。
> 通道 A（.spec/设计稿/）可对照 design-system token 机械比对；通道 B（外部设计稿）按像素目测比对，报告标注基准类型。

---

## 一、布局与结构（Layout & Structure）

- [ ] **页面骨架**：实现页的总体布局（顶栏/侧栏/内容区/底部）是否与设计稿一致——区块有无、顺序、占比不因实现变样；
- [ ] **区块对齐**：卡片/表格/表单/列表等区块的左右对齐、居中、栅格列分布与设计稿一致；
- [ ] **栅格与响应**：同一视口宽度下，栅格列数、断点行为与设计稿意图一致（用户指定视口内比对）；
- [ ] **多余区块**：实现页是否有设计稿中不存在的区块/模块（加戏，记问题）。

## 二、间距与尺寸（Spacing & Size）

- [ ] **内外间距**：卡片内边距、区块间距、列表行距、按钮内边距与设计稿一致（通道 A 对照 token 间距阶）；
- [ ] **宽高比例**：卡片宽高、按钮尺寸、图片/头像尺寸、行高与设计稿相符；
- [ ] **间距写死**：实现页是否用魔法数字间距（应还原设计稿 token 或用规范间距）。

## 三、颜色（Color）

- [ ] **主色/品牌色**：按钮主色、链接色、选中态、焦点环与设计稿一致；
- [ ] **语义色**：成功/警告/错误/信息色、文字主/次/弱层级色与设计稿一致；
- [ ] **背景色**：页面背景、卡片背景、悬浮层/遮罩背景与设计稿一致；
- [ ] **token 消费**：实现页色值是否走设计 token / 变量（通道 A 时以 design-system 色板逐项核对；发现规范外色值记问题并注明设计稿色 vs 实现色）。

## 四、字号与字重（Typography）

- [ ] **字号层级**：页面标题/卡片标题/正文/辅助文字的字号、字重、行高与设计稿层级一致；
- [ ] **字体族**：中西文字体/字重回退表现一致（系统字体差异标注为可接受差异）；
- [ ] **数字/金额**：数字字体、小数位样式与设计稿一致。

## 五、圆角、阴影与描边（Radius / Shadow / Border）

- [ ] **圆角**：按钮/卡片/输入框/弹框的圆角与设计稿一致（对照 token 圆角阶）；
- [ ] **阴影**：卡片/弹层/下拉的阴影层级、扩散范围与设计稿一致；
- [ ] **描边**：输入框/分割线/表格线的颜色粗细、dashed/solid 与设计稿一致。

## 六、层级与遮罩（Layering & Overlay）

- [ ] **视觉层级**：弹框/抽屉/下拉/提示浮层相对背景的层级（遮罩颜色深浅、内容置顶）与设计稿一致；
- [ ] **z-index 表现**：实现页是否存在本应浮在上层却被盖住的元素（浮层开合时）；
- [ ] **遮罩交互样式**：遮罩点击区域、半透明程度与设计稿一致。

## 七、图标、图片与插画（Icon / Image / Illustration）

- [ ] **图标集**：图标样式（线性/面性/粗细）、尺寸与设计稿同一套；
- [ ] **图片裁切**：头像/缩略图的裁切方式（圆形/圆角/比例）与设计稿一致；
- [ ] **插画/空态图**：空态插画、加载动画是否有且与设计稿风格一致（资源缺失或占位顶替记问题）。

## 八、状态与三态（States）

- [ ] **加载态**：骨架屏/进度条/loading 是否有且样式符合设计稿；
- [ ] **空态**：无数据时页面表现（文案/插画/引导按钮）与设计稿一致；
- [ ] **错误态**：接口失败时提示样式/重试入口与设计稿一致；
- [ ] **表单状态**：输入框 focus/hover/disabled/error 边框与提示样式是否符合设计稿；
- [ ] **组件状态**：开关 checked/unchecked、单选/复选选中样式、分页当前页样式与设计稿一致。

## 十、输出要求

- 每个差异点记一行到报告：`页面 | 比对项 | 设计稿（值/图） | 实现页（值/截图） | 严重度 | 修改建议`；
- **必须配截图**：实现页差异截图 + 与设计稿并排对照截图（见 `browser-guide.md`）；
- 严重度按 SKILL §二口径定级（整体走样 P0、局部明显偏差 P1、像素微差 P2）。
