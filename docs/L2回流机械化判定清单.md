## 判据能不能表达，先分两型（本轮补的分法，比上一格更可执行）

- **禁止式**（「不得…／不许把 X 写成 Y」）：结构层可用 tamper + `mustContain` 具体判据文本表达；
  行为层可用 `mustNotContain` + 分节／问句范围表达（锚 `^` 与跨不过否定字，防误杀合规回答）。
- **必含式**（「必须附三要件／必须含某节／必须逐条播报」）：结构层要靠 documentSections 双侧交集
  （本格不可动 `governance/artifact-registry.yaml`，且缺真实文档证据），行为层的禁词抓不到「没写」
  本身 ⇒ 一律不声明，宁可留着缺口。上一格把这型混在「需语义判断」里，本轮据此重查后仍不硬塞。
