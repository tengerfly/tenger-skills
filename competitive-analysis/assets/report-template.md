# 工业级竞品分析报告模板

> **使用规范**：
> 1. 按以下 11 个模块完整组织，严禁删减核心模块；
> 2. 遵守数据红线：无公开数据明确标注「暂无公开数据」，多方口径并列呈现，预测标示「此为预测/估算」，商业定价设计显式标注 `【平台设计假设值（非调研事实）】`；
> 3. 报告编写为候选草稿后，**必须通过 `assets/eval-template.md` 测试门禁（Pass Gate）验收**；
> 4. 验收通过后，在 `Competitive-Analysis/.output/<主题>竞品分析/` 下完成双文档落盘交付（`<主题>竞品分析报告.md` 与 `验收结果详细说明.md`）。
