# DEV

开发域。负责把已批准的 PRD、原型、UI 设计稿和技术方案落地为可运行代码，并通过代码评审交付测试域。

## 主流程

`Backend-Tech-Design` / `Frontend-Tech-Design` → `Backend-Dev` / `Frontend-Dev` → `Code-Review`；`Tech-Review` 为技术方案独立评审，OSS 调研由 `Other/OSS-Radar` 提供。

## 边界

- 技术选型在方案阶段一次性收敛，开发阶段不随意重选型。
- 代码实现必须以 PRD、TDD/FTDD 和接口契约为输入；可运行性、测试和提交证据是交付条件。
- 评审只审不改，问题通过任务清单回交开发或技术方案 Skill。
