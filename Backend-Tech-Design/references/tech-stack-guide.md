# 技术选型指南

> 用途：为技术选型澄清阶段提供推荐规则。所有选型必须给「选型 + 理由 + 备选」，禁止拍脑袋。

---

## 一、档位决策（每次必问，推荐企业级）

| 档位 | 特征 | 典型选择 | 适用 |
|------|------|---------|------|
| **企业级生产**（默认） | 集群、分库分表、读写分离、监控告警、CI/CD、安全加固 | K8s + 微服务 + Redis Cluster + Kafka | 正式上线、长期维护 |
| **快速实现** | 单机、最小可用、够用即可 | docker-compose + 单体 + Redis 单机 | MVP 验证、快速试错 |

> 判定口径：用户明确要「快速 / MVP / 先跑通」才走快速档；其余一律企业级。

---

## 二、语言推荐规则

| 需求特征 | 推荐语言/框架 | 理由 | 备选 |
|---------|--------------|------|------|
| 高并发 / 低延迟 / 微服务 | Go（Gin / Echo） | 并发模型强、部署轻、内存占用低 | Java、Rust |
| 企业级 / 生态成熟 / 团队 Java 背景 | Java（Spring Boot / Spring Cloud） | 生态完善、规范成熟、招人容易 | Go |
| AI / 数据处理 / 快速原型 | Python（FastAPI） | 开发快、AI 生态好 | Node.js |
| 实时 / IO 密集 | Node.js（NestJS） | 事件驱动、异步 IO | Go |

> 用 Node.js（NestJS）写 LLM / Agent 后端：以 `case-library/agent-templates.md` 的 NestJS + Vercel AI SDK 模板为起点。

---

## 三、数据库选型

| 场景 | 推荐 | 理由 | 备选 |
|------|------|------|------|
| 事务型业务（订单/账户） | MySQL 8 / PostgreSQL | 事务强、生态成熟 | — |
| 需要 JSON/复杂查询 | PostgreSQL | JSONB、窗口函数强 | MySQL |
| 企业级大数据量 | MySQL 分库分表 / PostgreSQL 分区 | 水平扩展 | TiDB |
| 快速实现 | PostgreSQL / MySQL 单库 | 简单够用 | SQLite（纯演示） |

---

## 四、缓存选型

| 场景 | 推荐 | 理由 |
|------|------|------|
| 热点数据 / 会话 / 分布式锁 / 限流 | Redis | 单线程、数据结构丰富、原子操作 |
| 企业级高可用 | Redis Cluster / 哨兵 | 高可用、水平扩展 |
| 快速实现 | Redis 单机 | 够用 |

> 缓存只做加速，不做数据源——缓存与 DB 一致性策略必须写清（Cache-Aside / 双删 / 过期兜底）。

---

## 五、检索选型

| 场景 | 推荐 | 理由 |
|------|------|------|
| 有全文搜索 / 复杂过滤 / 聚合分析需求 | Elasticsearch | 全文检索 + 聚合强 |
| 简单关键字搜索 | 数据库 LIKE / 全文索引 | 够用、省一个组件 |
| 快速实现 | 数据库 LIKE | 最快 |

> 无搜索需求不上 ES，避免过度设计。

---

## 六、消息队列选型

| 场景 | 推荐 | 理由 |
|------|------|------|
| 高吞吐 / 事件流 / 日志采集 | Kafka | 吞吐高、持久化强 |
| 业务解耦 / 延迟低 / 可靠投递 | RabbitMQ | 路由灵活、可靠性好 |
| 无异步解耦需求 | 不用 | 同步调用即可 |
| 快速实现 | 不用 / 简单异步 | 最快 |

> 有「异步通知 / 削峰 / 解耦」需求才上队列。

---

## 七、Docker 与编排

| 档位 | 编排 | 说明 |
|------|------|------|
| 企业级 | K8s（或 docker-compose 多服务起步） | 滚动发布、自动扩缩容、服务发现 |
| 快速实现 | docker-compose | 一条命令起全套 |

---

## 八、其它组件速查

| 组件 | 企业级 | 快速实现 |
|------|--------|---------|
| 对象存储 | MinIO / 云 OSS | 本地磁盘 |
| 网关 | Nginx / APISIX | Nginx 或框架内置 |
| 监控 | Prometheus + Grafana | 日志即可 |
| 配置中心 | Nacos / Consul | 配置文件 |
